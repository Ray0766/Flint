## 二、改动

**只追加样式，DOM 一个节点没动。** `web/app/globals.css` 末尾加一段（约 200 行），全部取 `_ds` 的 token：

| 改了什么 | 改前 | 改后 |
|---|---|---|
| 网格项 | 卡面是一张小卡，选入框、地区、各源原话、三个动作散在外面 | 整个网格项是一张卡；里面那层卡面去掉自己的边、底、内边距 |
| 选中态 | 只有复选框打了勾 | 卡的边换成 `--sulfur` 并加一圈同色细线 |
| 选入框 | 浏览器默认复选框加一行字，在卡的上方 | 卡右上角的一枚标签，勾上后换强调色 |
| 组合栏 | 没有样式，一行挤在屏头下面 | 一条有底有边的栏，**贴在视口底部跟着滚** |
| 各源原话、三个动作 | 12px | 13px；动作的点按高度不低于 32px |
| 网格 | 列宽下限 300 | 下限 340，窄屏收进视口 |
| 兜底日期那句 | 一行普通文字 | 兜底那一态用 `--ochre` 底与左边线标出来 |

既有的 `.hotspot-card` 规则一个字没删：卡堆与别的屏还在用，新规则只覆盖「在网格项里」的那一种。

## 三、自己定的（装饰性）

- 组合栏贴底用的是 `order: 99` + `position: sticky; bottom`。视觉上它排到了这一屏的最后，
  DOM 顺序没变——读屏与 Tab 顺序仍是先栏后卡。视觉顺序与 DOM 顺序不一致，这是有意的取舍；
- 窄屏（≤640px）上一张都没选时组合栏不贴底：390×844 实测贴底的栏高 186px，占五分之一屏；
- 选中态不换底色，只换边：换底色的话卡内正文的对比度要重算；
- 文案的措辞。
