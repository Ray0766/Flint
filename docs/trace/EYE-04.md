## 《怎么测》补了「界面」一节

三件写齐：**打开哪一屏 / 该看到什么 / 看着不对时看哪张图**，
外加「看着不对时先看这三处」——那三处正是本批实际踩过的：

1. 顶栏折成两行 → `--width-app-inset` 没生效；
2. 吉祥物只剩一条白尾巴 → 条上被加了 `overflow`；
3. 减动效开着还在动 → hover 那几条特异度更高，减动效块里少列了它们。

> 写「踩过的」而不是写「可能的」：可能的那种清单每一条都要人现场推理，
> 而这三条是**有人真的撞过**的，照着看一眼就能确认。

## 判据没有偷懒的地方

- 六种组合**逐一 parametrize**，缺一种就红（少一种就是「那一种没看过」）；
- 截图判**字节数 > 10KB**——一张 0 字节的文件也叫「截图在盘上」；
- 「三条意见」各有一条判据，直接对着 owner 的原话写。
