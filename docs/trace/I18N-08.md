## 3 一条额外守的：组件不自行推导语言
`切到 JP 也 NEVER 变成 ja` —— A3 反例第一条正是「切 region=JP 时把界面变日文」。
组件只把 `lang` **原样带回**，自己不做任何语言推导；
`data-lang` 属性也断言仍是 `zh`，防「回调没改但界面自己变了」。
