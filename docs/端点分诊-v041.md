## D · 该退役（0 条）

**一条都没有，而这是个结论，不是省略。**

判「该退役」要能指出**它已被谁取代**或**它服务的需求已经没了**。
这 35 条里，没有一条能从仓里证明这两件事的任何一件：

- `/design/render` 与 `/design/explore/render` 看起来重复，但两者的入参与门禁不同
  （一个出正式产物、一个出探索预览），**看起来多余不等于多余**；
- `/plaza/topics` 与 `/plaza/hot` 同理。

**把「我看不出它有什么用」写成「该退役」是猜。** 这一类留空，
比填一条没有依据的强。
