# 分析屏的取证样例簇没有判定，于是每次取证都带一条 404

**状态** open · 2026-08-12 · `WB-01`

不阻断（**当前行为是对的**：端点如实回 404，屏上如实说「还没有判定」）。
本单登记的是**那条 404 为什么在**，以及它什么时候该消失。
关联 `GATE1-REAL`（第 12 批） · `tests/v041/test_screens_live_probe.py#KNOWN_NOISY` ·
`tests/v041/test_mobile_sweep.py#CONSOLE_BASELINE`。

## 实况（2026-08-12 实测，真栈）

取证样例是 `c-20260629-088`：

| 请求 | 结果 |
|---|---|
| `GET /clusters/c-20260629-088/evidence-cards` | **200**（1498 字节，证据卡是真的） |
| `GET /clusters/c-20260629-088/verdict` | **404** |

屏上因此显示「还没有判定」——**那是实话**。
控制台里那一条 404 就是这一次问答留下的。

顺带记一条实况：**没有 `GET /clusters/{id}` 这条路由**，
今天挂着的只有 `/evidence-cards` 与 `/verdict` 两条（查 openapi 得）。

## 为什么这条 404 是对的，NEVER 修绿

`cluster_verdicts` 今天只有 `GATE1-REAL`（`DEC-057` 那一次真实分析窗口）
落下的 **2 行**，而取证样例不在其中。

三种修法里两种是坏的：

- **给这个簇编一条判定** → 那是三条铁律里「结论必有引用」的反面，
  编出来的判定没有任何证据支撑；
- **让端点在没有判定时回 200 + 空** → 「没判过」与「判过而结论为空」
  从此分不开，而这两件事该让用户做的事完全不同。

对的那种：取证样例改指一个**真有判定**的簇，或者按 `DEC-057` 的边界
再授权一次真实分析把判定跑出来（**那要 owner 点头**——真实网络是事前必审）。

## 这条为什么今天才被看见

三条判据（`test_fe_smoke` / `test_mobile_sweep` / `test_screens_live_probe`）
读的都是同一份 `.ui-probe/fe_smoke.json`，而那份文件**跑过一次就一直用**。
`WB-01` 因为新增一屏必须重跑全量取证，这条与另一条
（`docs/blocked/WORKBENCH-SAMPLE-ID-IS-A-PLACEHOLDER.md`）一起现形。

同一天同一个毛病在顶栏那条判据上更贵：
一次真实的 390 横向溢出被判绿了整整一批
（`docs/blocked/NAV-BAR-OVERFLOWS-AT-390.md`）。

## 什么时候撤掉这条额度

取证样例拿到判定的那一天。**NEVER 因为「反正它绿着」就把额度留着**——
留着的话，这一屏哪天真出一条别的报错，判据不会响。
