## Claude 侧的三处工程坑 + 处置（诚实）
1. **gzip 二次解压**：M1-008 `RecordingTransport` 重包留 `content-encoding` 头 → 对 Anthropic gzip 响应二次解压报错。加**压缩安全 `_RecordingTransport`**（录已解压 body、重包丢 content-encoding；不改共享件）。
2. **原生结构化拒开放键**：Claude `output_config.format`（`PaidTierProvider`）要求 object 显式 `additionalProperties:false`，与 keyword_mapping 开放键冲突 → 400。改走 **tool-use 结构化路径**（`MeteredAnthropicProvider` 基类），schema 宽松容开放键。
3. **thinking 吃预算截断**：sonnet-5 省略 thinking 会自适应思考，把 max_tokens=1024 预算吃光 → tool 输出截断、why_now/keyword_mapping 缺失。加 `_ClaudeToolProvider`（tool-use + `thinking:disabled` + max_tokens=4096）。曾观察一次「重生成」把 why_now/evidences 扁平（`$.why_now: type must be object`）→ 结构化耗尽（第三铁律 job failed）。故付费侧改**崩溃容忍批 `run_combo_batch`**（逐槽重试 ≤2、如实计 schema_misses、跳过不硬造；identity 重生成不再发付费调用）。本轮 misses=0。
