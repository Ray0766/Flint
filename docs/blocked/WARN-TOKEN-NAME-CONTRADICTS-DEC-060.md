# 卡面要落一个叫 `--warn` 的 token，而 `DEC-060` 把 `--warn` 列进「NEVER 引进本仓」

**状态** closed · 2026-08-12 · `TAIL-01`（开单人 `PAL-01`）

**不阻断本卡的其余部分**（换板的 16 个 token 全部落地）。
阻断的只有 `--warn`/`--warn-soft` 这一格——**值已经算好了，owner 定名字之后一行就能落**。

## 一、两处逐字对不上

**`DEC-060` 第一条**（本批首卡刚落进 `DECISIONS-v04.md`）：

> v4 交接包那 12 个变量名（`--bg` / `--panel` / `--panel2` / `--sub` / `--line` /
> `--accent` / `--ok` / `--bad` / **`--warn`** / `--unk` / `--shadow`）是**设计稿的记法**，
> **NEVER 引进本仓**。

**`tasks-v041-b15.json#PAL-01` acceptance④**：

> **v4 的 `--warn`/`--unk` 两族是新增，NEVER 覆盖既有 token**：以 **`--warn`**
> （明 `#a3701c` / 暗 `#c99a4a`）与 **`--warn-soft`**（明 `#e9deca` / 暗 `#352b1b`）
> 落成新 token。

同一个名字，一处说 NEVER 引进，一处说落成新 token。
按 `worker.md §1.4`：**发现两处矛盾 MUST 停下开单，NEVER 自行择一后不留痕**。

## 二、值已经算好，与名字无关

| 主题 | 告警色 | soft 底 | soft 怎么来的 |
|---|---|---|---|
| 明 | `#a3701c` | `#e9deca` | v4 `rgba(180,130,40,.14)` 合成到 `--paper #f2ede4` 上 |
| 暗 | `#c99a4a` | `#352b1b` | v4 `rgba(200,155,75,.16)` 合成到 `--paper #191612` 上 |

两个 soft 值与卡面给的数**逐字相同**——它们是算出来的，不是抄的
（合成规则与 `--moss-soft`/`--rust-soft` 同一条，本卡的判据算一遍再比）。

对比度实测：`#c99a4a` 在暗 `--surface #211d17` 上 **6.55**；
`#a3701c` 在明 `--surface #faf7f1` 上 **4.01**。

**明色那一格过不了 AA 正文线（4.5），要连同名字一起定**：4.01 够图形与大字号（≥3.0），
不够正文。落它的时候要么只用于记号/边框，要么按 `--ink-2` 那两处的同一手法压暗
（本卡另两处偏离就是这么处理的：改前值 / 改后值 / 实测比值三样都写在 `colors.css` 里）。
**这条我没有替 owner 定**——它与名字是同一格的事。

## 三、两种口径，各自代价

| 口径 | 名字 | 代价 |
|---|---|---|
| **甲 · 照卡面** | `--warn` / `--warn-soft` | `DEC-060` 那条禁令破了一个口子。禁令的意思是「设计稿的记法不进来」，破例之后下一个人无从判断还有哪几个名字可以破例——**一条有例外而没写清例外边界的禁令，等于没有禁令** |
| **乙 · 照本仓命名法** | 例如 `--ochre` / `--ochre-soft`（赭石，与 `--rust` 铁锈 / `--moss` 苔绿 / `--sulfur` 硫磺同一族命名） | 与卡面字面不符，需要 owner 一句话认定「名字换了、值不变」。本仓既有的四个性格色全是**材料名**，`--warn` 是**语义名**——混进来之后，命名法本身也有了两套 |

**我的看法（供参考，不是决定）**：乙更贴近 `DEC-060` 的原意——那条禁令挡的是
「两套命名并存、而组件读的是哪一套在屏上看不出来」，`--warn` 正是那种会并存的名字。
但这一格该由 owner 定，因为卡面写的是甲。

## 四、今天缺这一格不影响任何一屏

`--warn` 这一族是**新增**的：本仓今天没有任何组件在读它
（`web/` 下 `var(--warn` 出现 0 次，实测）。
所以它现在缺着，屏上什么都不少；等 owner 定了名字，落它是一行的事。

## 五、需要 owner 的什么

一句话：**甲**（照卡面用 `--warn`，并说明这条例外的边界）或
**乙**（改叫 `--ochre` 一类的本仓材料名）。


## 关闭（`TAIL-01` · 2026-08-12）

owner 2026-08-12 取**乙**：改叫 **`--ochre`（赭）**，**值 `#a3701c` 一个字不动**。
理由逐字是「仓里命名法是材料名（paper / ink / rule / indigo / sulfur / rust / moss），
而 `DEC-060` 把 `--warn` 列进『NEVER 引进本仓』」——与本单 §三「乙」那一行同一条。

落地在 `_ds/tokens/colors.css` 四个块里各一份（`:root` / media dark /
`[data-theme=dark]` / `[data-theme=light]`）：

```
--ochre:#a3701c;      /* v4 --warn */          明
--ochre-soft:#e9deca; /* v4 --warn-soft */     明（rgba(180,130,40,.14) 合成到 --paper）
--ochre:#c99a4a;                               暗
--ochre-soft:#352b1b;                          暗（rgba(200,155,75,.16) 合成到暗 --paper）
```

两个 soft **是算出来的**（判据现算一遍再比），与 `--rust-soft` / `--moss-soft` 同一条规则。

**§二那一格没有含糊过去**：`#a3701c` 在明 `--surface` 上实测 **4.01**——
够图形对比（3:1）**不够正文**（AA 4.5）。所以用途边界写死在 token 注释里，
且各配一条判据：全仓没有一处 `color: var(--ochre)`（正向），
以及**阴性对照**——把它挂到一段正文上必须被抓住，并报出实测比值
（阴性对照改在内存里，NEVER 动真文件）。

值与名分开处理这一点是本单最有用的地方：值早在 `PAL-01` 就算好了，
卡了三天的只有名字。
