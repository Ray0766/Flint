S1 · 通用件

全批 20 屏复用的地基件。每件列 props 契约；无专属端点，均为设计决策。
状态标记 StatusMark（DS 现成 · 八态）
每态同时有非颜色载体（记号形状 / 边缘质地 / 底纹）；批次二起大量使用。
props: { status: "verified"|"review"|"blocking"|"disputed"|"speculative"|"void"|"sealed"|"degraded"; label?: string } 映射：speculative←why_now.speculative · review/blocking←needs_review+review_severity · disputed←disputed_mark · sealed←locked∨author=="user"∨user_modified · degraded←degraded
加载骨架 LoadingSkeleton
一切 GET 等待态。只表等待，不表进度——后端无进度数据时不画百分比。
props: { lines?: number = 3; height?: number = 12; label?: string } label 显示所等待的端点（mono），如「载入中 · GET /plaza/hot」。
空态 EmptyState（DS 现成）
插画只出现在空态与缺口。陈述句，不道歉、不卖萌。空态不是错误。
props: { title: string; description?: string; actionLabel?: string; onAction?: () => void; illustration?: "spark"|"lens"|"page" } 用法：clusters=[]∧weak_signals=[] →「该日无热点」；evidence_cards=[] →「该簇暂无证据卡」。
通用错误 ErrorState
说清发生了什么、怎么办。色彩纪律：仅 409 EXPORT_BLOCKED / 503 用 --rust；其余错误一律墨色 + 划线纹警示记号。
HTTP 400 · VALIDATION_FAILED
发生了什么：day 参数格式非法。怎么办：改为 YYYY-MM-DD 后重试。
HTTP 503 · SERVICE_UNAVAILABLE
发生了什么：该格式暂不可用（如 pdf 引擎缺失）。怎么办：换用其他格式，或等待服务恢复。
props: { httpStatus: number; code: "LEDGER_CONFLICT"|"EXPORT_BLOCKED"|"PERMISSION_DENIED"|"BUDGET_EXCEEDED"|"NOT_FOUND"|"VALIDATION_FAILED"|"SERVICE_UNAVAILABLE"; what: string; how: string; retry?: { label: string; onClick: () => void }; detail?: object } --rust 仅在 code ∈ {EXPORT_BLOCKED(409), SERVICE_UNAVAILABLE(503)} 与阻塞级复核时出现。
404 NotFound
仅用于路由/资源确实不存在；空数据（空列表）绝不渲染成 404。
真实触发：
props: { path: string; onHome: () => void; homeLabel?: string = "回热点广场" }
