## 3 三条判断（都写进模块 docstring）
**① 缓存键必须含 translator 版本**：少了它，换译者/模型之后旧译文会被当成新译者的产物返回——
`TranslatedText.translator` 标记与内容对不上，而那个标记正是 B8 让 UI 显示「机翻」的依据。
另：原文按**字节**入键，全角与半角是两个不同的原文，**NEVER 归一后再算键**（归一 = 认为它们可共用一份译文）。

**② A7 降级不是抛错，也不是返回原文**：降级返回的是「**没有译文**」这个明确信号。
返回原文冒充译文会让 UI 把原文当译文显示，B8 的机翻标记就成了谎。

**③ 降级结果 NEVER 入缓存**：服务恢复后还从缓存拿「没有译文」，就成了**永久降级**。

## 4 只吞一种异常
`translate_or_degrade` 只捕 `TranslationUnavailable`。别的异常是**程序错误**，
NEVER 被降级掩盖成「服务不可用」——那会让一个 bug 表现成一次外部故障，永远查不到。
`test_translation_unavailable_is_the_only_swallowed_error` 用一个抛 `ValueError` 的假译者守着。
