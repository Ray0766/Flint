## 二、既有 12 屏（v04 变化逐屏登记，细节以基线为准）

> 这 12 屏的完整交互与端点在基线 `docs/前端功能说明.md` 里，**NEVER 在此复制一份**——
> 两份细节会各自漂移。这里只登记 v04 带来的变化，未列变化即「按基线不变」。

### 2.1 热点广场

`GET /plaza/hot` 增 `region` query；不传 `region` 时行为与基线逐字相同（增量不破坏）。

### 2.2 证据卡面板（原「工作台（证据卡）」）

更名 + 归位为图谱工作台内抽屉面板，见 §四定名方案（`owner_review: true`）。

### 2.3 combo 入口（关联假设建项）

空假设由服务端判 `EMPTY_HYPOTHESIS`（F8/F9 同一判据），前端本地预检话术与之一致。

### 2.4 主题列表 + 选主题

**主题没有名称**（`DEC-036`，owner 2026-08-08 裁）。冻结件 `Topic` 的全部字段是
`topic_id / seed_id / one_liner / target_user_tag / form_factor_tag / why_now /
keyword_mapping / embedding`——原文名与译名槽**都不在其中**。

> **作废（`DEC-036`）**：这一段原先要求主题屏上「名称三元组」，主行取 `name_native`、
> 机翻译名为次要行。那句话是从热点簇那边抄来的（**簇确实有**，见 `#2.14`）。
> 给 `Topic` 补两个没人产出的字段，只会让屏上出现一个永远没有译名的三元组——
> 那看起来像翻译服务坏了，而真相是这个实体从来就没有名称。

- **主行**：`one_liner`（主题的一句话，它就是这个实体的标识）。
- **次要行**：`target_user_tag` + `form_factor_tag`。**它们不是译文**，NEVER 带机翻标记。
- **why_now**：`claim` 上屏；`speculative` 为真时**标出来**，NEVER 与已证事实同形呈现。
- **选主题**：落到 `chosen_topic_id`，前端 NEVER 自己记一份。
- 这一屏出现任何「机翻」标记都是错的：**它没有一个字是译文。**

### 2.5 Gate 视图（四分类全字段）

证据 `by_source` 分列**增 region 维度**（§6-H6，NEVER 合成单一结论句）；
`AuthorityTier == "unknown"` 的证据 NEVER 满足判 A/B 的必要条件。

### 2.6 分析 Job + SSE 渐进

三种新 JobKind（translate / design_generate / template_solidify）复用**同一** SSE 事件流（§6-H4）。

### 2.7 报告查看器

引文以译文呈现时，出处槽 MUST 可展开到原文（`PRINCIPLES#B9`/`#B10`）；
不能展开的 Block 标 `needs_review`，导出按既有 blocking 拦截。

### 2.8 干预层（lock / regenerate / dispute / evidence）

按基线不变。

### 2.9 指令式重生成（块级）

按基线不变。

### 2.10 受众选择（五模板 vs vibe_pack）

按基线不变。

### 2.11 导出（docx / pdf / html / markdown / vibe_pack zip）

按基线不变；导出门禁沿用既有管线（§6-H3）。

### 2.12 categories（大类目录）

按基线不变。

## 三、六类新屏（逐屏含状态呈现规则）

### 2.13 语言/地区设置

- **做什么**：两个独立下拉——系统语言 `SystemLanguage ∈ {zh,en}`、地区 `Region ∈ 九区`。
  两值独立存 user profile，**切地区 NEVER 改语言，切语言 NEVER 改热点集合**（`PRINCIPLES#A3`）。
- **端点**：`GET/PATCH /me/preferences`【未建·接口预留】。
- **状态呈现规则**：
  - 未登录/无 profile → 显示默认值（zh / CN）并标「未保存」，NEVER 用浏览器 `Accept-Language` 推地区。
  - 保存中 → 两个下拉置灰；保存失败 → 保留用户选择并显示错误，NEVER 回滚成旧值假装成功。
  - 切换后热点集合重新拉取；语言切换**不**触发热点重拉（正交性可见证据）。

### 2.14 热点卡片广场（C 组）

- **做什么**：卡片式浏览热点，卡面显示 `Cluster` 的 `name_native` 主行 + 机翻译名次要行（`PRINCIPLES#B8`）。
- **端点**：`GET /plaza/hot?region=`【已建，增 query】。
- **状态呈现规则**：
  - 加载中 → 骨架卡；空结果 → 「该区当日无数据」并给出可切换的区，NEVER 回落到别的区假装有数据。
  - 单区源全灭 → 该区卡片区显示缺数据角标（E6 新降级行），其余区照常。
  - 译名缺失（翻译服务不可用）→ 只显示 `Cluster` 的 `name_native` 单行（A7），NEVER 用原文冒充译文。

### 2.15 收藏图书馆（D 组）

- **做什么**：收藏的热点/主题/交付物列表，支持 stale 标记。
- **端点**：`GET/POST/DELETE /favorites`【未建·接口预留】。
- **状态呈现规则**：
  - 每条显示 stale 与否——stale 判定来自后端 `Revalidator` 统一口径，**前端 NEVER 自行按时间戳推断**。
  - 被收藏对象的 snapshot 受冻结保护（E2-P1），列表 NEVER 出现「已收藏但内容已被清理」的空壳。
  - 空态 → 「还没有收藏」+ 去广场的入口。

### 2.16 热点工作台·图谱（F 组）

- **做什么**：节点（热点/证据卡/主题/假设）+ 边（关联假设）的画布；双击节点打开 **2.2 证据卡面板**抽屉。
- **端点**：`GET/POST /workbenches`【未建·接口预留】。
- **状态呈现规则**：
  - 空图 → 引导「从广场拖入第一个热点」，NEVER 预置示例节点冒充用户数据。
  - 边假设为空 → 服务端 `EMPTY_HYPOTHESIS`，前端在建边时本地预检并给同样的话术。
  - 移动端**只读**（E10）：可看可缩放，不提供增删改控件。
  - 撤销走全局既有 undo 链（§6-H5），NEVER 为图谱另起一条栈。

### 2.17 AI 设计工作台（G 组）

- **做什么**：自然语言 → 生成页面/组件设计，`iframe.srcdoc` 零构建预览；可固化为模板。
- **端点**：`POST /design`【未建·接口预留】；固化 → `template_registry`。
- **状态呈现规则**：
  - 生成中走流式（复用既有 SSE 通道），逐块出现；中断可续。
  - 模板注册表不可用 → **固化与生产渲染阻断**，探索期不阻断（E6 新降级行）——按钮置灰并说明原因。
  - 预览失败 → 显示原始产物与错误，NEVER 用上一次成功的预览顶替。

### 2.18 外链只读查看页（E3）

- **做什么**：`/share/{token}` 匿名只读查看交付物。
- **端点**：`GET /share/{token}`【未建·接口预留】；token 查 `share_links`。
- **状态呈现规则**：
  - viewer 是匿名 `Principal` 子类型，走**同一** JWT 中间件（§6-H2），NEVER 新写鉴权分支。
  - token 失效/过期 → 明确区分「链接已过期」与「无此链接」，NEVER 一律报 404 含糊过去。
  - 只读：不显示任何干预控件；导出按既有门禁（blocking 块存在时拦截）。

## 四、2.2 与 F 组并屏定名方案

`owner_review: true` —— 本方案偏离清单未提及处，MUST 由 owner 复核。

- 现 2.2「工作台（证据卡）」→ 更名 **证据卡面板**，作为图谱工作台内的**抽屉面板**（双击节点即达）。
- `/workbench` 路由归 **F 组**（热点工作台·图谱）。
- 理由：两处都叫「工作台」会让路由与文档双向歧义；证据卡是图谱节点的详情视图，从属关系比并列更贴合实际使用路径。
