## 四、怎么做的

**压一层，不重写。** 新增 `web/app/redesign.css`，在 `web/app/layout.tsx` 里排在 `globals.css` 之后：

1. **token**：用 `:root:root`（特异度高一档）重定义 `_ds` 的颜色、字体、圆角、投影、底纹 token。
   全仓样式本来就「零裸色值、全走 token」，所以换 token 等于全站换肤。`_ds/tokens/*.css` 一个字没动；
2. **外壳**：导航仍是 `<nav class="anime-nav">` 那棵树，用样式把它从「顶部居中的药丸」变成「左侧一条」。
   吉祥物与发光块 `display: none`。窄屏下七个入口各自 `position: fixed` 排成底部标签栏；
3. **屏框与通用件**、**各屏**：逐类覆盖。

DOM 没有换，`data-*` 断言面一个没动。

**今日精选那一排**用了 `!important`：卡堆的位置是组件用内联 `transform` 摆的，
样式表要压过内联样式只有这一条路。组件的逻辑（当前张、键盘、拖拽）照旧在跑。

**撤回**：去掉 `layout.tsx` 里那一行 import，屏上回到 `UIR-03` 的样子。

## 五、判据

`tests/v041/test_redesign_layer.py`（8 条）。这层是设计，长什么样判据不管；管的是出了错屏上看不出来的那几种：

| 判据 | 注入的 bug | 结果 |
|---|---|---|
| 排在 `globals.css` 之后 | import 顺序倒过来 | 1 failed |
| 色值只在 token 那一节 | 组件里写死一个色值 | 1 failed |
| 暗色两条通道同值 | 手动暗色改一个值 | 1 failed |
| 文字对比度 ≥ 4.5（明、暗各 21 对） | 元信息字调浅 | 1 failed |
| 覆盖的 token 名字对得上 | 拼错一个 token 名 | 2 failed |
| 退役的两样不显示、窄屏标签读得到 | 吉祥物放出来 / 标签改 `display:none` | 各 1 failed |

**判据是实现之后写的**，不是之前。设计层没法先写一条会红的断言再去画；写完之后七处注入逐个验过它们会红。
这一点与 S2-9 的顺序不符，记在这里。

对比度是按 WCAG 2.1 公式从文件里的色值实算的：明色 21 对最低 4.63；暗色第一版有一对 2.07
（浅色字压橙底），为此加了 `--on-accent`（两套主题都是深色），改后暗色全部过线。

## 六、自己弄错、当场改掉的

1. **窄屏标签栏的字**第一版用 `display: none` 藏起来。那会把它从无障碍树里拿掉，
   链接在读屏里就成了没有名字的图标。改成裁成 1px 的视觉隐藏，并补了判据守着；
2. **屏头的说明标签**第一版是两枚标签套在一起（外层我给的样式 + `_ds` 贴纸组件自带的内联样式）。
   改成外层给长相、里层全部压平；
3. **今日精选**第一版每张卡 300 多像素高、中间全是空白——槽位的内联高度没压掉；
4. **长文屏的屏头**没和下面那张纸对齐（后写的 `margin` 把居中盖掉了）。
5. **颜色写错了地方**。第一版把新配色定义在 `redesign.css` 里。全量门禁红了 7 条：
   `test_palette_v4`（「颜色有了第二个来源」「组件里写死了颜色」）、`test_tail_01`（「`_ds/tokens/` 之外又有颜色字面量」）、
   设计约束 A5（那个保留的告警色出现在别处）。它们拦得对——颜色只有一个来源这条规矩与换不换板无关。
   改成把新取值写进 `_ds/tokens/colors.css` / `typography.css` / `spacing.css`（上一次换板 `PAL-01` 也是改的这个文件），
   `redesign.css` 里现在一个色值都没有；
6. **进行中的状态标签**第一版用琥珀色画字，撞上「那个颜色只做图形与底、NEVER 画正文」。改成琥珀底、墨色字；
7. **工作台在新外壳下撑不满一屏**：旧外壳的 `.app-shell` 是一列 flex，新外壳不是，中栏底部的输入框与
   「生成计划书」被挤到视口外。给工作台的正文区定成一屏高，改后发送键底边 1043px < 视口 1080px。

## 九、新设计没有解决的

- **内容本身**：报告正文里的 id、计费屏那句后端原话、热点分析页 14 行一样的「关键词 1 · 标记 1 · 链接 1」——
  换了皮，字还是那些字；
- **热点卡里的层次**：地区码仍是孤零零的一行；
- **`globals.css` 里三千行旧规则还在**，其中药丸条、吉祥物、麻纸那几百行已经是死的。新设计定下来之后另开一卡清；
- **`_ds` 的贴纸标签、状态印记组件**（`_ds_bundle.js`）自带纸感的内联样式，屏头那一处压平了，别处没有逐个看；
- **新字体没有随包分发**：字体栈第一项是 Inter，本机没装时落到苹方 / 系统字体。没有引入字体文件（那是新增依赖）。
