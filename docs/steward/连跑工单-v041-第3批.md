### B 组 · 契约对齐（TYPE-01~04，4 卡）

对账表 62 条发现里，装配之外还剩 11 条：

| 类 | 数 | 什么意思 |

### C 组 · S1 通用件（UIX-01~03，3 卡）

### D 组 · 尺子加宽（GAUGE-07~09，3 卡）

**`GAUGE-07` 是本批第二值钱的一张**。`PRINCIPLES#A3` 是两条轴——语言与地区，而 `tools/check_locale_seam.py` 的字面量集合里**九区代码一个都没有**。下面这两种写法从它下面走得过去：

```python
if region == "CN":            # 分支假设，尺子不红
select_sources(region="CN")   # 调用点写死，尺子不红
```

`BE-07` 的变异考⑳ 就是这么过的。这把尺子自己的 docstring 写着「一处硬编码今天是一行，V2 全球版时是一处要回头找的暗坑——**而它不会报错**」。地区那一半现在就在这个状态。

`GAUGE-08` 补换行符尺：**一个 CRLF 就能让全仓「先剥注释再判」的尺子集体失效**（JS 正则的行终止符定义）。这次表现为假红——安全的一侧；同一条缝在另一个方向上会给出假绿。

`GAUGE-09` 对第 2 批 89 张卡做 `acceptance ↔ 尺子`清点，办法照 `GAUGE-02`。
