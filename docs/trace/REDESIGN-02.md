## 二、改了什么

| 屏 | 改前（`REDESIGN-01` 之后） | 改后 |
|---|---|---|
| 报告 | 引用到的实体 id 与正文同一种字；表格没有线；开头的声明就是一段字 | id 是等宽的小标签；表格有表头底色与行线；声明是一块浅底说明；缺口提示是琥珀色左边线的提示框；图表与质量卡的占位是虚线框；底部两行入口做成次按钮 |
| 热点分析 | 14 条证据一行一条横贯全屏；判定、证据、各源三段散着 | 每段是一块卡；证据排成网格；「还没判」是一块浅底说明 |
| 广场卡 | 地区码是孤零零一行粗体字，下面一个带圆点的列表；热度是普通文字 | 地区是一枚标签、后面跟着各源原话；热度是一枚强调色标签 |
| 作业屏 | 步骤是一行行 `outline start` | 时间线：每步前一个圆点，完成的是绿色；阶段印「开始」「完成」 |
| Gate 判定（还没判）、关联假设建项（没从热点卡进来） | 左上角一句话 | 那句话做成一块居中的空态 |

**标记上的两处小改动**（其余全是样式）：

1. `SourceColumns.tsx` 的四层节点补了类名（原先一个都没有，样式只能挂在 `data-testid` 上）；
2. 作业屏步骤的阶段：屏上印 `job.step.phase.start` / `end` 的文案，原值留在 `data-step-phase`；
   表里没有的值原样印（`screens.test.tsx` 的桩用的是 `done`，照旧原样印出来）。

报告正文那一棵树是封版件（`DEC-021`），**一个节点没动**：样式全部挂在它已有的 `data-*` 属性上。
