# 答作率门槛说明（owner 裁决 @2026-07-30，落地件）

> 本文件是「免费档选型 + 答作率门槛」裁决的门槛出处与不变量说明，供
> review_gate 复核「门槛出处 + 不变量」。代码落点：
> `eval/semantic_answers.py`（REFERENCE_RATE_UNIFIED_JUDGE / GATE_RATIO /
> relative_answer_gate，test-first：tests/m4/test_answer_gate.py）。

## 一、绝对 0.90 线**作废**
- 旧 `CHECK_ANSWER_LINE = 0.90` 系对**旧「自评」考核面**（各模型自己判自己、
  且原为模板 check_questions 面）所定——**出处已断**：考核面已换 held-out
  bank v1.0（owner 投放，129 题，与模板题零交集），且判官口径不一使跨家
  数字不可比。故 0.90 **NEVER 再沿用**（作绝对达标线）。

## 二、新门槛 = 相对付费参照（可横比）
- 同一 held-out bank v1.0 + **统一判官 claude-sonnet-5**（output_config.format
  结构化判分）下重判三家现成产出，得可比作答率：

  | 被判产出 | 统一判官作答率 | 出处 trail |
  |---|---|---|
  | claude-sonnet-5（付费，repair-on） | **0.434**（112/258） | assets/prod_caliber/unified_judge/claude-sonnet-5.json |
  | gemma4:31b（免费，reasoning-off） | **0.395**（102/258） | assets/prod_caliber/unified_judge/gemma4_31b.json |
  | qwen3.6:27b（免费，reasoning-off） | **0.357**（92/258） | assets/prod_caliber/unified_judge/qwen3.6_27b.json |

- **参照天花板** `REFERENCE_RATE_UNIFIED_JUDGE = 0.434`（claude-sonnet-5 统一
  判官、bank v1.0）——数字出处 = 上表 unified_judge trail（可复现）。
- **门槛线** `GATE_RATIO = 0.85`：免费档作答率达 **参照 × 0.85 = 0.369** 即
  合格。ratio 为 owner 可修订门槛线（走 PDD 修订通道），非绝对质量线。
- 判定（`relative_answer_gate`）：`passed = free_rate >= REFERENCE × GATE_RATIO`。

## 三、免费档默认模型 = qwen3.6:27b（依据：权威中文能力榜）
- **选型依据 = 权威中文能力榜**：Qwen 3.6 在中文上明显领先 Gemma——
  **C-Eval 92.8 vs 81.4**（榜单称「中文独一档」，owner 引据 @2026-07-30-b）。
  这是「中文分析 AI」最相关的维度（综合中文能力），故据此定免费档默认
  = **qwen3.6:27b**（原 gemma4:31b 更正）。
- **内部覆盖指标转内部参考**：统一判官覆盖率 gemma 0.395 > qwen 0.357——
  **与权威榜结论相反**。据实透明记录此分歧，NEVER 隐藏。取权威榜而非覆盖
  指标的理由：覆盖指标是**窄代理**（held-out 单节答问，天花板仅 ~0.43），
  权威榜测的才是产品所需的**综合中文能力**。
- **为何这不是「移动球门」**：覆盖指标的缺陷（窄代理、天花板低、判官偏差）
  在**知道它与权威榜分歧之前**就已**独立查实**（§13/§六：自评→统一判官
  剥离出判官偏差、天花板 ~0.43 是判官上限而非模型上限）——不是为了让 qwen
  当选才事后贬低该指标。且 **GATE_RATIO 恒 0.85 NEVER 下调**（倒推门槛=作弊，
  明令禁止；反倒推不变量见 tests/m4/test_answer_gate.py）：qwen 覆盖 0.357
  **仍不过**覆盖门，选型与覆盖门**解耦**——依据是权威榜，不是把门调到 qwen
  过。
- 读数保留项（覆盖指标内部参考用）：Claude 判 Claude 或略自家偏松；claude
  自评→统一判官 Δ 仅 +0.004，不显著。

## 四、口径与不变量
- **原始分数一律不改**（可复现铁律）：`semantic_answer_report` 恒 report_only，
  只出原始 rate；本门槛是**独立的 gate 判定**，NEVER 回改任何已产出分数。
- **免费档 = best-effort 分析 AI**，NEVER 作绝对质量保证（对外表述纪律）。
- 付费档与免费档 reasoning-off **不可直接比**；横比只在**统一判官**下成立。
- 禁令：NEVER 改题库/SCALE/模板/组稿/提示词；本裁决不跑任何模型（record +
  gate test 落地）。
