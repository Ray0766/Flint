## 三、不动的东西（以及为什么）

1. **调色板的取值**。v4 那一板是 `DEC-060` 定的，token 值一个不改。「丑」如果指的是这套米色与橙色本身，
   那是换一板的事——改 `_ds/tokens/colors.css` 一个文件，要 owner 点头。
2. **浮动导航条与吉祥物**。`NAV-ANIME-01` 逐字要「条本身是 fixed」，吉祥物是 owner 2026-08-10「要，做全」。
   它滚动时会盖住内容的第一行，这是浮动条的固有代价。
3. **今日精选的卡堆**。出处是 `前端设计/Flint 热点线索卡堆叠`，owner 自己的设计稿。两侧的卡是斜的、读不了字，
   这一点记在第五节问 owner。
4. **路由与入口**。24 屏、7 个入口不增不减。
5. **DOM 上的 `data-*` 断言面与零计算**。能只改样式就只改样式。
6. 冻结件、`_ds` 供应商资产。

## 四、方向（我定的，装饰性决定）

同一板颜色，重做的是**结构与层次**：

- 一件东西画成一张完整的卡（底、边、圆角、内边距齐全），里面不再套一层卡；
- 没有样式的区域全部补上，控件只有一套长相（主按钮沿用 `.chain-form__submit` 的取值）；
- 元信息 13px 起，正文 14 至 16px；
- 长屏上的操作条贴住视口；
- 屏上的话用产品语言，不印单号、id、枚举原值；
- 空态居中并给出下一步；阅读屏居中、行长照 `--measure-longform`。
