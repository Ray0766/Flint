## 2 acceptance ②（zh 默认、en 可切、未登录回落 zh）
`web/lib/i18n/config.ts` + 6 条测试（`npm test -- --run lib/i18n` 全绿）：
- 语言集恰是 `zh`/`en`，默认 `zh`；
- `en` 可切；
- 未登录 / 无 profile / 空串 → 回落 `zh`；
- **非法 locale 回落而不抛错**——抛错会让整页白屏，而这只是个偏好；
- **地区码 NEVER 被当成语言**（`resolveLocale("JP") === "zh"`）：
  A3 反例第三条就是「用 Accept-Language 推 region」，反过来同样禁止；
- 两份 messages 键集一致（I18N-02 会填全量 key，本卡只放可加载的最小占位）。

真相源写死在 docstring 里：**profile（服务端）**，NEVER 读 `navigator.language`——
那会让同一账号在不同设备上看到不同语言（与 I18N-06「跨设备一致」同一条理）。
