## 二、判据为什么不是「编号出现了」

只断言编号在的话，写一行 `- **DEC-035**：见工单` 也能过——**而那等于没记**。
下一个人（或下一个会话的我）看到「维持 DEC-034」时，无从知道当时权衡的是什么，
于是要么盲从、要么把它重开一遍。

所以每条挂一组**它必须提到的关键事实**：

```
DEC-035 → region · 迁移 · 「静静地什么都不筛」
DEC-036 → Topic · 名称三元组 · 改规格
DEC-037 → 403 · 取证样例 · 白名单
DEC-038 → DEC-034 · 「已经有主」 · 标签文字
```

另加四条：正文 >200 字（防「只记结论」）· 影响面里要有**具体的名字**（反引号包着的
文件/卡号/端点，NEVER 只说「影响前端」）· 署名与日期（**它能被复核的前提**）·
`DEC-038` 是「维持」，所以**要写代价**——不写的话下一个人会以为它是免费的。

## 三、追加式，NEVER 回改
