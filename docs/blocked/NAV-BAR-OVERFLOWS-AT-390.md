# 390 下药丸导航条的右边几项在屏外，而两条判据都说没事

**状态** closed · 2026-08-12 · `WB-01`

`WB-01` 现场逮到并一并修了。留单是为了记住**那两条判据为什么没响**。
关联 `NAV-ANIME-01`（第 13 批） · `tests/v041/test_shell_nav.py` ·
`web/app/globals.css#NAV-ANIME-01`。

## 实况

390 视口，改前实测（7 项时）：

| 项 | 右边缘 |
|---|---|
| `/plaza` | 181.45 |
| `/favorites` | 239.45 |
| `/design` | 297.45 |
| `/settings/locale` | 355.45 |
| **`/account`** | **413.45** |
| **`/demo`** | **471.45** |
| **`/workbench`** | **529.45** |

视口宽 390。**后三项整个在屏外**，而屏上没有滚动条、没有省略号、
没有任何「这里还有东西」的提示。

6 项时是同一回事：`/demo` 的右缘 471.45——**这不是 `WB-01` 引入的**，
是 `NAV-ANIME-01`（第 13 批）把顶栏换成固定药丸条那天起就有的。

## 为什么两条判据同时说没事

**一 · 「零横向溢出」判的是文档，而条是 `position: fixed`。**
fixed 元素的溢出不会把 `document.documentElement.scrollWidth` 撑大——
于是 `EYE-04` 六张截图逐张量到的「零横向溢出」是**真的**，
而它量不到这件事。屏上不出现横向滚动条，正因为如此，
那三项不是「滚出去了」，是**消失了**。

**二 · 「顶栏不溢出」判的是一份落盘缓存，而缓存是药丸条之前录的。**
`test_the_bar_does_not_overflow_at_390` 读 `.ui-probe/nav04_shell.json`，
改前的取法是「文件在就直接用」。那份文件是第 13 批之前录的，
量的是折行的旧顶栏——它当然不溢出。

**两条各自都对，合起来漏掉了整件事**：一条量的东西天生看不见 fixed，
另一条量的是上一版的屏。

## 怎么被逮到的

`WB-01` 加第 7 个入口，`/account` 的右缘从 355.45 变成 413.45，
越过了那条 `<= 390.5`——**判据是对第 5 项响的，而第 6 项早就在屏外了**。
换句话说：它响得晚了整整一批。

## 两处修法

**一 · 屏**：<768 那一档让条**折行**，照本仓自己写下的那句话
（那条判据的 docstring）：「折行是对的，横向滚出去不是：
顶栏滚出去的那几项，用户根本不知道它们在」。
连带三处：折行后发光块会横跨两行 → 窄屏改成给当前项底色；
`flex:1` 的占位会把控件顶到第二行最右 → 窄屏收起；
吉祥物坐在条外 `top:-48px` → 窄屏收起（`NAV-ANIME-02` 的判据全在 1920 量，一条没动）。

修后实测：7 项全在 390 内，`/demo` 与 `/workbench` 落在第二行
（右缘 116.5 / 164.5），零控制台报错。

**二 · 判据**：缓存改成**按输入指纹失效**——
`AppShell.tsx` + `globals.css` 的内容哈希写进产出，对不上就重拍。
指纹在**拍完之后**盖：拍之前盖的话，探针失败会留下一份
「指纹对得上而内容是旧的」缓存，比没有缓存更坏。

## 留给下一个人的一句

本仓还有几处「取证落盘、文件在就不重跑」的判据（`.ui-probe/` 下各家）。
**它们全都有这个毛病**：缓存不会自己知道被拍的东西变了。
`WB-01` 只修了顶栏这一处；其余各家按同一形状补指纹是下一批的活。

## steward 2026-08-12 的裁断：这不算 worker 的漏，是判据漏了一维

> 「**『零横向溢出』这条正向判据对 position: fixed 的元素无效**——fixed 溢出不撑
> 文档 scrollWidth，所以它在药丸条身上恒绿。而我自己复核第 13 批时**也只看了
> 1920 两张截图、没看 390**。
>
> 往后视觉判据里凡是 fixed / absolute 的元素，量法 MUST 是
> 「最右元素右缘 ≤ 视口宽」，NEVER 用文档级的横向溢出去代替。
>
> 你把取证缓存改成按输入指纹失效，这一手同样重要——**读缓存的判据等于没有判据**。」

两条都已写进 `docs/trace/WB-01.md`，并从 `EYE-05` 起执行。
