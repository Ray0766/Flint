# 技术约束清单（每批迭代复用）

> **用法**：每批产出后重新贴回会话，说"逐条跑一遍，不通过就改，并说明改了什么"。只跑与本批相关的条目。
>
> 这里全是**功能正确性**问题——界面显示了后端没给的东西，或漏掉了后端明确给出的状态。风格自由不受这份清单限制。
>
> **为什么要反复贴**：迭代到后期，模型会为了画面更干净而合并、省略或美化状态标记。那不是设计变好，是数据显示错了。

---

## A. 全批通用

1. **有没有凭空造数？** 是否出现可靠度进度条、百分比、星级、雷达图，或任何把布尔/枚举画成连续量的表达？后端不返回这类分值。
2. **有没有造端点或造字段？** mock 的键名 / 取值域 / 结构是否与文档示例 JSON 逐字一致？有没有为了页面完整而发明字段？
3. **未建接口有没有被含糊过去？** `citation_id` / `chart_id` / `card_ref` / `hints_ref` / 三通道值解引用，是否都留了取数位并明确写"接口未提供"，而不是显示假内容或空白？
4. **状态标记有非颜色载体吗？** 每个状态是否同时有记号形状 / 边缘质地 / 底纹？灰度打印还分得清吗？
5. **`--rust` 有没有被挪用？** 只留给阻塞标 / 409 / 503。插画、装饰、强调里出现了吗？出现就等于废掉了阻塞标。
6. **空态、错误态、加载态齐了吗？** 每屏三态是否都做了？空态是不是被做成了错误？
7. **无专属端点的屏标注了吗？** P14 项目总览、S0 外壳导航，是否写清由哪几个端点组合、哪些是设计决策？

## B. 批次一（外壳与入口）

8. **排序动了吗？** `/plaza/hot` 是否按后端返回顺序渲染，无前端重排、无排序控件？
9. **`by_source` 合并了吗？** 四个源是否仍各自独立可读，没有被合成一个数或画成堆叠图？
10. **`flags` 保真吗？** `novelty` / `momentum` / `revival` 三种旗标是否各自可辨，没有被合并成统一标签？`top_links` 可点吗？
11. **空态不是 404 吗？** 未知簇返回 `evidence_cards: []`、未知 project 返回空 topics，是否渲染成空态而非错误页？
12. **combo 校验对吗？** 卡数 2~5、假设非空，不合规是否禁用提交？`degraded == true` 是否明示"部分主题为降级生成"？

## C. 批次二（主题与分析）

13. **推测态有没有被升格？** `why_now.speculative == true` 是否降权且**抑制了溯源入口**？示例里第二个主题渲染出来了吗？
14. **进度是真的吗？** 是否按真实 `state` / `step_name` / `phase` 展示，没有编造百分比让它看起来在动？
15. **失败态如实吗？** `state == "failed"` 是否显示 `error` / `reason` 原文，没有假装完成或转圈到底？
16. **SSE 接线对吗？** 是否先读快照再带 `Last-Event-ID` 续订、按 `seq` 去重、终态自动关闭？有没有另造 SSE？
17. **verdict 直取吗？** 四分类是否按后端值展示、前端不判定？`constraints_checked` 是否按**对象**处理而非 boolean？
18. **缺口分类对吗？** `missing_permission` 是否走"请 owner 授权"而不是"去补数据"？两个入口不同吗？
19. **`unknown` 竞品呢？** `strength == "unknown"` 是否与 `weak` 不同形、明确标"未知"？

## D. 批次三（交付物）

20. **保护块是"不存在"还是"置灰"？** 满足 `locked ∨ author=="user" ∨ user_modified` 的块，是否**不渲染**任何编辑 / 再生成 / 删除 / 指令框？
21. **两级复核标分得开吗？** advisory 可折叠不阻断导出、blocking 阻断导出并高亮 `blocking_block_ids`，两者一眼可辨吗？
22. **三通道混了吗？** 事实 / 价格 / 涉我是否靠记号形状区分、互不混用？有出处的值全部等宽 + `tabular-nums`？散文里还有裸数字吗？
23. **`quantity` 算了吗？** `100.0` 是否原样呈现、未做乘算？
24. **图表零计算吗？** 零数据点、零图表库、零聚合，并说明了数据出处链？
25. **缺口被填了吗？** `gap_notice` 是否保持为有形的空缺，没有被生成文字填满？
26. **乐观锁走确认流了吗？** 409 `LEDGER_CONFLICT` 是否取 `detail.current_version` 提示后带 `confirmed_version` 重提，没有静默重试、没有丢用户输入？
27. **evidence 结果自判了吗？** 是否只显后端回值？`alignment == "partial"` 是否标"部分支持、未成事实"？
28. **503 装死了吗？** pdf / pack 的 503 是否显示"该格式暂不可用"，没有转圈或伪装下载？

## E. 批次四（分叉与收尾）

29. **受众强制单选了吗？** 是否**没有**默认帮用户选？选 `ai_executor` 是否锁定 `vibe_pack`？
30. **422 吞掉了吗？** 受众混用的 422 是否如实报错？
31. **vibe_pack 查看器和报告有区别吗？** 它是给 AI 执行的包，排版上是否与给人读的报告明显不同？
32. **预留位标注了吗？** R1 账户 / R2 额度 / R3 质量卡，是否都明确写了"端点未建"，而不是做成看起来能用的假功能？
