## B. 完整设计（五法一个不落，复用血缘 Δ/momentum/bge-m3）

> **计分位置**：广场排序分 `hotness` **按现 total_heat 同法在读时算**（查 heat_points 近 N 日时间序 → 组合分 → 排序），
> **phase 1 不落库、不改契约**（同 total_heat 现状）。突发/弱信号态若要跨日累积（phase 2/3）须持久化 → 见 S9。

### ① 排序：速度 + 加速度 + 时间衰减（吃血缘日间 Δ）

对每簇取 heat_points 的 `agg_norm(d) = Σ_源 norm_score(d)`（现 total_heat 即 agg_norm(today)），构近 N 日序：
- **速度** `v = agg_norm(today) − agg_norm(today−w_v)`（复用 momentum 的 Δ 口径，w_v 初值 1~3 日）；
- **加速度** `a = v(today) − v(today−w_a)`（二阶差分，w_a 初值 1 日）；
- **时间衰减**：仿 HN `score = (base − 1) / (T + 2)^G`（T=距 first_seen/末次爆发的**日龄**，G=gravity 初值 1.8）；
  或 Reddit `hot = sign·log10(max(|base|,1)) + age_seconds/45000` 的日粒度变体。
- **组合**（推荐 HN 式，直觉稳）：`hotness = (α·agg_norm + β·max(v,0) + γ·max(a,0)) / (T_days + 2)^G`。
  α/β/γ/G 初值 `1/0.6/0.3/1.8`，**临时初值真跑 + 登记标定通道**（类比 θ_rel/δ）。

### ② Kleinberg 突发检测（抓真爆发：novelty+growth）

对每簇 agg_norm 日序跑 Kleinberg 两态突发自动机（低/高速率态 + 状态切换代价 γ_k），标 `burst=True` + `burst_weight`：
- 输入：日增量序列（Δagg_norm）；输出：突发区间 + 强度。**纯离线 CPU**（序列短、每簇独立）。
- `hotness *= (1 + λ_burst·burst_weight)`（λ_burst 初值 0.5）。突发态跨日累积须存 → phase 2 落库（S9）。

### ③ 新颖度加权（新簇 > 常年热）

`novelty_boost = f(簇龄)`：first_seen 近（NewClusterEvent/first_seen）→ 加权；常年高 norm 老簇不吃 boost。
- `hotness *= (1 + ν·novelty_factor)`，`novelty_factor = max(0, 1 − age_days/novelty_horizon)`（novelty_horizon 初值 14 日，ν 初值 0.4）。
- 直接复用 `signals.py` novelty 判定 + Cluster.first_seen。

### ④ 跨源同时爆发加权（弱信号→强信号）

不再线性 Σ：奖励**同日在多源同时冒头**（跨源印证）。
- `cross = 当日 norm>θ_cross 的源数`（θ_cross 初值 60）；`multi_boost = 1 + κ·max(0, cross−1)`（κ 初值 0.3）。
- `hotness_final = hotness · multi_boost`。数据现成（heat_points 每源 norm，API by_source 已有）。

### ⑤ bge-m3 弱信号早期跟踪（BERTrend/Snapchat 路线 · 差异化点）

早期抓"小而在加速"的语义新趋势：
- **簇内语义紧致度** `coh = 关键词嵌入对质心的平均 cosine`（bge-m3，复用 cluster/daily 质心）——紧致上升 = 成形中；
- **嵌入邻近新兴** `emerge`：新簇质心与近日新簇/关键词的语义邻近密度上升（BERTrend「popularity×嵌入」思路）；
- `weak_signal = coh 上升 且 v>0 且 agg_norm 尚低`（小而在加速）→ 单列「早期弱信号」轨（不与主榜混排，或低权并入）。
- **须跨日质心历史**（现只存当前 Cluster.centroid，无每日历史）→ **契约不足，S9 等 owner**（见下）。

## C. 产品级选择（owner 定 · 我给推荐 + 理由，NEVER 替拍）

**排序哲学：广场"什么浮上来"？**
- **偏新颖爆发**（novelty+burst 权重高、衰减快 G↑）：广场更"实时/尝鲜"，抓早期弱信号，但噪声/昙花多。
- **偏跨源印证**（multi_boost/agg 权重高、衰减慢 G↓）：广场更"稳/可信"，多源冒头才上，但慢半拍、错过独源早爆。

**我的推荐（owner 定）**：**中性偏跨源印证 + 单列弱信号轨**——主榜用「速度+加速度+时间衰减+跨源」求稳可信（商用广场
可信度优先），**另开「早期弱信号」小轨**（⑤）满足尝鲜，两不相扰。衰减 G≈1.8（HN 手感）、跨源 κ 中等。
**理由**：V1 商用 MVP，广场可信度 > 猎奇；弱信号单列既拿差异化又不污染主榜。**但"多快浮上来/多偏爆发"是产品口味，owner 拍。**
