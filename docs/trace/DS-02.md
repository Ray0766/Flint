## 三、两处「我本想照做、核完决定不照做」

### 3.1 Gate 四分类 **不**一一映射到 `_ds` 八态（DEC-034）

素材右上角那枚记号在五张示例卡上是五个不同的态，很想让 Gate 的 A/B/C/D 一一对上。
核过之后不能那么做：**`_ds` 的八态在本仓每一个都已经有固定含义**——
`disputed` 是 fact 的 `status=="disputed"`（S2-4：NEVER 被新生成引用）、
`sealed` 是被锁的 block（S2-5）、`degraded` 是 B7/E6 的降级生成、
`speculative` 是还没提升的 claim、`blocking` 是阻塞/409/503。

把 `B_red_ocean` 涂成 `disputed`，屏上「这条结论有争议」与「这个赛道是红海」就共用一个记号，
而前者是铁律级的事实状态。**借一个已经有主的记号去说另一件事，比不给记号更坏。**

所以只做零冲突的那一档（`web/components/hotspot-card/verdictStatus.ts`）：

- `D_insufficient` → `void`（证据不足 = 有形空缺，语义逐字相同）；
- 其余三类 → `verified`（共同点：判定已出且全引用，Gate① 铁律），**分类本身由标签文字承载**。

代价说清楚：A/B/C 三类在记号上看起来一样，比素材少一层可扫性。
**这一条请 owner 裁**——若要四档各有各的记号，那是给 `_ds` 加记号，不是借现成的。
已登记 `DECISIONS-v04.md#DEC-034`，并写进第 5 批完成态报告的待裁项。

### 3.2 素材的 20px / 25px 不照抄，取 `--sp-5`

素材是单文件预览，间距直接写像素（`margin: 20px 0 0`、贴纸高 25px），
而这两个值**不在 `_ds` 的间距刻度上**（4/8/12/16/24/32/…）。
`tests/v041/test_ui_restyle.py::test_the_new_styles_declare_no_font_size_or_spacing_of_their_own`
这把既有尺子当场把它们报了红——**它报得对**：全站间距只该有一套刻度。
取最近的 `--sp-5`（24px），差 1~4px 换「刻度只有一套」。

## 五、判据是怎么防「类名在、样式没有」的

主判据 `test_no_class_is_left_with_zero_styling`：探针在**真页面**里铺一棵卡面树，
再铺一个裸 `<span>` 当基线，逐类比 19 项计算值——**一样 = 零样式 = 判红**。
改前那一版正是「逐条相同」。

配套两条防漂移：

- `test_every_class_the_component_emits_is_measured`：类名从组件源码解析，
  组件多一个类而没人量它 → 红（`native-name__mark` 就是被这条揪出来的，本卡顺手补了样式）；
- `test_the_card_face_matches_the_asset_declaration`：期望值**从 `.dc.html` 解析**，
  判据里零手抄——手抄的话「照素材做」会退化成「照我当时记下的样子做」。
