## 二、ts 字段的真实语义（如实交代）

**ts 是执行者手写的「叙事序标记」，不是机器时钟读数。** 各会话内由
执行者按事件先后手排（会话内单调），日期取自该会话感知的系统日期——
跨会话时该感知日期发生过前移与回退（154~358 行区段写下了 07-29/30/31，
后续会话又回到 07-28），造成整账日历值漂移与第 359 行大回跳。

## 三、可信度界定

| 字段/性质 | 可信度 |
|---|---|
| 行序（append-only 文件位置） | **权威**——事件先后的唯一真相 |
| task_id / event / note / cycles_used | 可信（复审逐轮核对过） |
| ts 会话内相对先后 | 基本可信（手排单调） |
| ts 绝对日历值 | **不可信**——尤其第 154~358 行区段；07-28 早段行的时刻值同样是叙事序非钟面 |
| BACKFILL 行 ts | 按判例携双时标（推测动手点 + note 内补录时点），语义自明 |

引用台账时间的正确姿势：引行序与事件，NEVER 引 ts 作日历证据。
