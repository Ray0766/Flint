## 4. 「未找到公开端点」是一条结论（acceptance④）

- **`CN`**：微博热搜与百度热搜**没有官方公开 API**。搜到的全是**第三方转售**
  （天聚数行 / 极速数据 / 幂简集成），既非源站官方，也过不了「可定位 + 结构稳定」。

- **`AU` `SG` `GB` `IT` `FR`**：本轮未搜到各区**本土**官方端点，只能靠
  `google_trends_api` 按地区参数兜底，而那条本身是 alpha。

**「未找到公开端点」与「该区没有源」不是一回事**：前者是本轮调研的边界，
后者是结论。文档里把这句话写出来了。

## 6. 四个不自决的问题（owner_review）

1. **多区源怎么落表**：`SourceEntry.region` 是单值。Google Trends 这类按参数分区的源，
   按区拆条目（口径不破、条目膨胀）还是给契约加「多区」标记（**动冻结件，走 PDD**）？
   本轮先按注册地落 `US` 一条并登记。
2. **Reddit 走不走商务流程**：非商业免费档对商用 MVP 不适用；用它就要申请商用合作
   （人工审批、按调用计费）——**付费/商务触点，NEVER 自决**。
3. **五区靠 alpha 兜底可不可接受**：`AU` `SG` `GB` `IT` `FR` 目前只有 Google Trends
   一条路。要么接受这个风险，要么这五区先按 E6 缺数据行走空表。
4. **权威度是初判**：按「是不是该平台自己的官方端点」判，**K3 的方法论会覆盖它**。
