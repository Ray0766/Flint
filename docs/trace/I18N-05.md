## 2 acceptance 逐条
| acceptance | 测试 |
|---|---|
| 译文引用**必带**原文展开交互 | `译文呈现时必带展开控件`：有 display 就必有 `quote-expand` |
| 展开态渲染 `source_field` 指向的原文**字节** | `展开后渲染 source_field 指向的原文字节`：`textContent` 与原文逐字相等（样本含全角数字 `２０２７`），并断言 `data-source-field="quote_span"` |
| 无原文数据时**只显原文槽** | `无译文数据时只显原文槽`：不出现展开控件——**NEVER 显示一个「展开原文」按钮却展开出同一段文字**，那是假交互 |

## 3 两处额外守的
- `aria-expanded` **如实**反映开合（不是摆设属性）；收起后原文节点消失；
- **原文 NEVER 被译文替代**：展开前后原文字节一致，且断言译文 ≠ 原文——
  防「译文槽里塞的其实是原文」这种假译文。
