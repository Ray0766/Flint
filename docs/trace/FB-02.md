## 3. 记号长什么样：照 `_ds` 的既有约定，不发明

`_ds/readme.md` 原话：「不用图标字体、不用 emoji、不引 CDN 图标库；识别物是『印记』：
小尺寸单色几何记号（实心方 = 事实、空心方 = 价格、括线 = 涉我、三角 = 阻塞、**斜纹方 = 争议**）」。

斜纹取 `_ds` 现成的 `--tex-hatch`——`tokens/texture.css` 里那一行的注释原话就是
「**划线底纹（争议）**」。**NEVER 在应用层自己写一条 `repeating-linear-gradient`**：
那等于把「争议长什么样」复制出第二份真相，`_ds` 改了角度或浓度这里不会跟着变。
测试单独钉这一条（`test_the_mark_reuses_the_ds_hatch_token`），并反向断言
`_ds` 那个 token 的「争议」语义还在——它哪天改语义，本卡口径要跟着改而不是继续用。

落地规则（`web/app/globals.css`）：

```css
.mark--disputed{
  display:inline-block; width:.72em; height:.72em;
  margin-inline-end:.28em; vertical-align:-.04em;
  background-color:var(--surface);      /* 实底：见下 */
  background-image:var(--tex-hatch);    /* _ds 的「争议」斜纹 */
  border:1px solid var(--ink-3);
  color:var(--ink);
}
```

**为什么给实底而不是留透明**：斜纹是 `background-image`，透明底下
`getComputedStyle().backgroundColor` 取到 `rgba(0,0,0,0)`，对比度就无从算起——
EYE-02 的判据在这种情况下判红，**而且它判得对**：取不到有效背景色本来就不该假装算得出。

零新颜色：`--surface` / `--ink-3` / `--ink` / `--tex-hatch` 四个都是 `_ds` 已声明的。

## 6. 三次撞上同一类问题（值得单独记）

本卡的禁用字形断言首版扫 `globals.css` **原文**，当场红——因为注释里逐字写着
「改之前用户看得见一个 ⚠」（在说明这条规则替掉的是什么）。
**这是本批第三次**：GAUGE-06 的新 docstring 引了旧 `hasattr` 断言原文、
FB-01 的注释引了那条会 500 的 `@import` URL。三次的修法完全相同——
**判据落在代码层，不落在解释代码的话上**（剥注释后再扫）。

反过来说也成立：如果为了让断言过而把注释里的病史删掉，留下的就是一份看不出
「为什么这么写」的代码。**留痕与判据不该互相取消**，这三次都是按这个原则处理的。
