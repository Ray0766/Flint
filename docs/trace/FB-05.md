## 4. 三条产品判据

### ① 金额由后端算，并把算式摊开

响应给 `price_low` / `price_high` / `quantity` / `amount_low` / `amount_high` / `unit` / `item` /
`source` —— **参与运算的每一项都在**，那个金额随时能被复算。

`quantity` **必填且 > 0**：默认成 1 会让「忘了传数量」与「真的只要一份」长得一模一样，
而算出来的金额照样像个正经数字。小数数量照算（0.5 个月的托管费是真实场景），NEVER 取整。

### ② 时效：过期照实标记，NEVER 静默用旧价（D13）

判定**复用** `flint/pricebook/stale.py:check_stale`，响应回 `stale` / `yellow_flag` /
`price_year` / `price_data_note`（后者复用 `price_data_notes`，文案「单价数据为 {year} 年」）。

有一条测试专门钉「复用而不是另写」：直接调房规函数，断言端点的三个字段与它逐个相等。
**在端点里另写一套 TTL 的那天，预算表上的黄标与质量卡上的注记会开始各说各的。**

夹具造了一新一旧两条（2026-07 与 2023-01，TTL 12 个月，今天注入为 2026-08-04），
过期那条断言 `stale=True` 且 `amount_low` 照常算出 60.0——**过期不影响算术，只影响标注**。

### ③ 币种照实，汇率不编

只回 `currency` 本身。两条断言：响应里**不许出现**任何含 rate/exchange/converted/fx 的字段；
源码里不许出现疑似写死的汇率（`6.x` / `7.x` 后跟乘除）。
K8 未定，**编出来的一条汇率会让整张预算表的数字全部失去出处，而且没人看得出来**。
