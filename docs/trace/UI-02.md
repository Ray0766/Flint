## 4. 判定归属仍由调用方持有（acceptance②，DEC-012）

判定按 **job** 键落在 `snapshots['snap-{job}-verdict']`；**cluster → 判定没有持久化真相**
（`GET /clusters/{id}/verdict` 不存在，乙案登记在 v0.4.1 候选清单、未开工）。
所以：

- Gate 屏路由是 `/gate/[id]`，`[id]` 就是 **jobId**——把「这条对应关系谁说了算」写在 URL 上；
- 广场屏那个「查看判定」入口**只在 URL 带 `?verdictJob=` 时才可点**，
  那正是「调用方持有」的形态；没带时标「未判定」，且**一个 verdict 请求都不发**；
- Gate 屏缺 jobId 时同样先判后发（`if (!jobId) … return`）。

**为什么不猜**：猜一个 job 去问，猜错时用户会看到**另一个热点的判定**并把它引进计划书。
判据不只看渲染结果，还看 `fetch` **被调用了几次**（vitest `expect(fetchMock).not.toHaveBeenCalled()`）。

同一条纪律用在 Gate → 报告那一跳：判定与交付物之间也没有持久化对应关系，
所以「查看报告」也是 `?deliverable=` 带来才可点。

## 5. 闸门阻断说清原因与块（acceptance③）

后端契约（`flint/api/deliverables.py#render`）：

| 后端 | 机器码 | detail | 屏上 |
|---|---|---|---|
| 409 | `EXPORT_BLOCKED` | `blocking_block_ids` / `violations` | **先说原因**（几个块挡着），再逐块列出，每条一个跳回报告锚点的链接 |
| 503 | `SERVICE_UNAVAILABLE` | —— | 「该格式暂时不可用」，不转圈、不伪装下载 |
| 其他 | —— | —— | 如实报状态码 |

三件不肯含糊的：

1. **三种结局各有各的落点**，NEVER 合成一句「导出失败」。409 是用户**能自己解决**的，
   503 是他**等就行**的，合成一句就都变成「不知道该怎么办」。
2. **错误体读不动时不猜**：当成 `failed` 如实报状态码。猜一份 detail 出来，
   屏上就会列出一串不存在的 block id，而用户会真的去找它们。
3. **后端没给清单时如实说**（`export.blocked.no_detail`），NEVER 显示一个空列表——
   空列表看起来像「没有块被挡住」，而导出确实被挡住了。

**色彩纪律**：`--rust`（`--alert-blocking`）全站仅三处，409 EXPORT_BLOCKED 是其一；
503 **不用** rust（它不是坏消息）。判据按分支判别式切开源码逐支查。

**503 也按机器码认**（写判据时发现的）：第一版只看 `res.status === 503`。
反代或网关也会发 503，那种 503 不是「这个格式暂时没接上」，
把它说成后者会让用户一直等下去。改成与 409 同款：状态码 + 机器码都对上才认。

### 7.1 一个我自己造出来的假绿，判据把它逮住了

第一轮取证：`/plaza` 与 `/jobs/[id]` 各 1 条控制台 404，`/gate/[id]` 1 条。
用 playwright 逐条打出失败请求的 URL（没有猜）：

```
/plaza          404 http://localhost:3000/plaza/hot?day=2026-07-04   ← 打到了同源
/gate/m1004-j   404 http://localhost:3000/jobs/m1004-j/verdict        ← 同上
```

根因：起栈时我给的是 `NEXT_PUBLIC_FLINT_API_BASE`，而 `web/lib/apiBase.ts` 读的是
**`NEXT_PUBLIC_FLINT_API`**。名字错一个词，浏览器把所有取数打回同源，`/plaza/hot` 404，
**广场屏渲染的是错误态——而 HTTP 状态仍是 200、页也不横向溢出**。

只判 200 的话，一个「读不到数据」的广场会以全绿的样子过关。所以补了一条判据：
广场屏必须**零控制台报错且页高 > 1000px**（真数据下实测 3915px，错误态是 900px）。
改的是起栈方式，不是代码。这与 UI-01 撞到的 `FE-DEMO-ENV-FLINT-API-BASE` 同一族，
那张单**本批不处理**（工单 §五）。
