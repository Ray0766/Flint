## 决策日志
- **两读取器 `load_deepseek_tier`/`load_openai_tier`（仿 `load_anthropic_tier`）**：共享 `_load_cloud_tier(source, prefix, default_base_url)`；严格读 `{prefix}_API_KEY/MODEL/USD_PER_MTOK_INPUT/_OUTPUT`；缺任一/非数字价 → `ProviderWiringError`，**报错只列变量名、NEVER 回显任何值（尤其 key）**；空串视同缺失。
- **base_url 厂商内置默认**（owner 令）：DeepSeek=`https://api.deepseek.com`、OpenAI=`https://api.openai.com/v1`；`{prefix}_BASE_URL` 可选覆盖（厂商换址时不改码）。
- **新 `CloudTier` dataclass**（api_key/model/base_url/价双项）——比 AnthropicTier 多 base_url（云端各家址不同）。放 production.py（与 anthropic tier 平行），非冻结件。
- **CloudOpenAIProvider 接 combo（模型无关一行切档）**：V2-002 地基，OpenAI 兼容 text-JSON 结构化（继承 LocalProvider），api_key 必填、按注入 ModelPricing 真实计费。harness `record_cloud(vendor)` 用它录制（同 claude 的压缩安全 transport + 崩溃容忍批），`_check_cloud_or_stop` 两家自检（未设→STOP 只列变量名）。
- **replay 分派改按 `asset["pipeline"]`**（batch/orchestrate），比按 model 名更稳（覆盖 claude/deepseek/gpt 付费侧批 + qwen orchestrate）。既有 qwen/claude asset 补 `pipeline` 字段（qwen=orchestrate、claude=batch，据实——本就那样录的），无需付费重跑。
