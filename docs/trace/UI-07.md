## 2. 三条来自 v2 2.13 的硬规则

### 2.1 NEVER 用浏览器语言推地区

v2 原话：「未登录/无 profile → 显示默认值（zh / CN）并标『未保存』，
**NEVER 用浏览器 `Accept-Language` 推地区**」。

浏览器语言推地区是**双重猜测**：先从语言猜国家，再把猜出来的国家
当成他要看的热点集合。猜错时用户看到的是另一个国家的热点，而他从没选过。
判据扫源码：`navigator` / `Accept-Language` / `languages` 一处都没有。

而且「显示默认值」要**说出来它是默认值**（`data-locale-unsaved`）——
不说的话，zh/CN 看起来像「他设过的」。

### 2.2 两轴正交（`PRINCIPLES#A3`）

`onChange` **一次只交出一根轴**（`(axis, value)`）。把两值打包成一个对象交出去的那天，
调用方就会顺手把另一根也写回去——BE-07 那侧 `set_prefs` 的
「只改传进来的那一项」是同一条纪律的后端形态。

vitest 把 **18 组合（2 语言 × 9 地区）逐个走了一遍**，每次都断言另一根没动。

### 2.3 保存失败 NEVER 回滚

v2 原话：「保存失败 → 保留用户选择并显示错误，**NEVER 回滚成旧值假装成功**」。

回滚之后屏上是旧值、没有报错，用户会以为自己没点到——他会再点一次，然后再失败一次。
判据钉在**渲染取值**上：两个下拉的 `value` 恒是 `draft`（用户选的），
源码里 `value={saved` 一处都不许有。

保存中两个下拉 + 按钮一起置灰（v2 原话）。
