## 0. 关键前置发现（决定全局）

**§3.5 合规硬约束**：`flint/sources/throttle.py:81` `check_metadata_only` 是巡检守卫——扫 public schema
全部列名，凡命中全文正文列名（`throttle.py:16` `FULLTEXT_COLUMN_NAMES`：`content/body/fulltext/full_text/raw_text/raw_html/html/article_text/page_content`）
即判**违规**，注释明文「**采集层永不落原文正文**」（PDD v0.2 §3.5，M1-016）。系统自产内容豁免
（`blocks.content`）。→ **落"外站全文正文"本身违合规**，不只是加字段。这把门 1 从"契约方便"重定义为"合规政策"。

**两条 Doc 生产路径必须分清**（易混）：
- **Path A（查询式，Gate①）**：keywords → `FourStepQueryBuilder.build`（`retrieval/query_builder.py:35`）→ `Query`
  → `Searcher`（`jobs/gate1.py:79`）→ Doc → `LLMRelevanceJudge.hit_rate` / `search_with_rewrite` / `merge_results`。
  已建，**缺真实 Searcher**（现 `_offline_searcher` 造 `.example` 合成 Doc，`gate1.py:138-166`）。喂 **Gate①**。
- **Path B（卡链接式 = 本总开关）**：`evidence_cards.top_links`（具体 URL）→ 抓每条 URL → 抽正文/quote →
  Doc（绑卡）+ Citation(quote_span) → 喂 **topic 生成器**。**几乎全缺**。这才是"让卡变厚"。
- 本 Feature B = **Path B**。Path A 是 Gate① 的证据面，与卡厚度正交（但抓取机制/Doc 表可互相复用）。

## 1. 精确缺口（整链逐段：已建 / 缺 / 占位）

## 2. 门 1（契约）· 正文存哪：三方案对比（NEVER 现在改契约）

`Doc`（`contracts/models.py:241`）= doc_id/source_id/kind/title/url/published_at/meta(JSON)/origin/access——**无 content 字段**。
`Citation`（:256）= citation_id/doc_id/locator/**quote_span**——quote_span **已在冻结件 + 已建表列**（`0006:49` nullable Text）。

| 方案 | 动作 | 合规（§3.5） | 契约 | 代价/风险 |
|---|---|---|---|---|
| A. `Doc.content` 全文 | 加冻结件字段 + 加 `content` 列 + 迁移 | **违规**：`check_metadata_only` 直接判 `content` 列违规（禁落全文） | 动契约（PDD 门） | 合规红线 + 契约门；最重、最不推荐 |
| B. `Doc.meta['content']` 全文 | 塞 JSONB，无 schema 改 | **违政策**：列名检查扫不到 JSONB 键 → **规避检测**（合规规避味） | 不动契约 | 表面省事、实质破 §3.5 不落全文，埋雷 |
| **C. `citation.quote_span` 短支撑段（推荐）** | 用既有 quote_span 列存**短引用段**（非全文） | **合规**：短引用非全文正文，`quote_span` 不在禁列名单 | **不动契约**（字段已冻结、列已建） | 抽取须产"短相关段"而非全文；与 Citation 设计原意一致 |

**推荐 C**：Doc 保持元信息级（title/url/date/meta），支撑证据 = 每条 citation 的 quote_span 短段。
既不动契约、又守 §3.5「不落全文」、又贴 Citation 冻结设计（locator+quote_span 本为此）。
**若 owner 日后要全文**（例如喂 RAGAS 更厚 context）：那是 §3.5 政策变更 + 契约变更 = **owner + 合规双决策，STOP**，NEVER 自行加 content。

## 3. 门 2（真实源）· top_links 指向哪、可抓性、路线（NEVER 自行开抓）

**路线（供 owner 选，NEVER 自行开抓、抓取即联网本轮禁）**：
- **R1 · 洁净子集先行（推荐起步）**：只抓 **github + arxiv（58%，公网 API、低风险）** → quote_span（README 首段 / 摘要句）。
  weibo/news 缓办。零付费、合规低风险、部分变厚。
- **R2 · 证据 API 补 news**：新闻走付费证据/新闻 API → **付费、V1 非目标 → STOP 待 owner**。
- **R3 · 只用卡已有元信息（不抓）**：不抓正文，仅用源侧已抓到的 title/date 富化——但这与 @2 现状增益小。
- **weibo（29%）**：反爬 + 登录 + robots + 合规风险高 → **明标 owner 决策**，NEVER 自行抓。

**触发 STOP 的点**：任何真实抓取（联网，本轮禁）；付费源（news API）；weibo/登录墙/robots 合规判断。均 owner 决策。
