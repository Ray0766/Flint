## 四条通用排障

1. **改了代码而屏上没变** → `:8000` / worker 跑的是改动之前的进程。两个都重起。
2. **修完仍报同一个旧错** → 可能有**两个 worker** 在抢作业，旧的那个没有新代码。
   `Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like "*run_worker*" }` 看几个。
3. **「没配」与「坏了」是两句话** → 503 + `FAMILY_NOT_CONFIGURED` = 这一族还没有后端（等下一版）；
   502 / 500 = 后端在、这一次失败（可以重试）。全站按这条口径分。
4. **空列表 ≠ 没查过** → 屏上四态（`not_checked` / `not_provided` / `empty` / `failed`）
   一条都不合并。看到「还没有」时先确认它说的是哪一态。
