# 证据管线 · 空壳诊断（owner @2026-07-31 授权只读排查 · NEVER 动实现）

> 问题：证据卡为何是空壳（keyword + top_links，有据 fact 中位数 = 0）？「卡的链接源本该怎么抽成
> 实质内容/事实」——没建 / 没接 / 没跑？只读诊断 + 证据（文件行号 + DB 计数）+「要让卡变厚须补哪一段」。
> 纪律：只诊断、给方案，NEVER 动手实现；命中冻结件不足或需付费抓取 → STOP 报 owner。

## 一、实体模型意图（冻结件 contracts/models.py）

- `EvidenceCard`（#94）：`card_id / cluster_id / keyword_ids / flags / top_links`——**索引级**，无正文、无日期、无 fact。
- `Doc`（#241，PDD 称 Evidence）：`doc_id / source_id / kind / title / url / published_at / meta / origin / access`
  ——**有 title/url/日期/meta，但无 content/body 字段**（全文无处安放，除非塞 meta）。
- `Citation`（#256）：`citation_id → doc_id + locator + quote_span`——**引用指向 Doc**（不是卡）。
- `Claim`（#308）→ 提升 → `Fact`（#327）：Fact `origin="promoted_claim"` 必来自 `cited + alignment=="supports"` 的 claim
  （下游 compose/freeze 产出）。**采集侧不产 fact**——此设计正确。

**意图链**：源文 → `Doc`(实质内容) → `Citation`(钉 doc_id) → Gate① 对齐 → `Claim` → 提升 `Fact`。
卡只是索引；实质取证靠 Doc。

## 二、实况（文件行号 + DB 计数）

### 采集→卡（M1）：建 ✓ 接 ✓ 跑 ✓
- `flint/cards.py` `build_card`（:63）：卡 = cluster 关键词 + `rank_top_links(link_candidates)`（:42）——
  **top_links 是 URL 字符串列表**（`return [url for url, _ in ...]` :60），**不抓正文**。
- DB：`trend_items_raw=1044` → `evidence_cards=1027`（clusters 193 / keywords 195）；`daily_ingest` job ×41。
  → 采集管线真跑过，卡按设计建成（薄）。

### 卡→实质内容（fetch top_link 源文 → 抽正文/claim → Doc 绑卡）：**没建**
- 全仓无「取 card.top_links → 抓源文 → 抽正文」的阶段。`selectolax`（HTML 解析）仅用于
  `flint/sources/weibo.py`（抓热搜**榜单**）与 `throttle.py / testing`，**不用于抽文章正文**。
- `top_links` 的消费点只有 `flint/api/views.py`（展示）、`flint/jobs/ingest.py`（写卡）、`domain/models.py`（字段）
  ——**从不喂给 retrieval/evidence 层**。卡的链接与 Doc 生产互不相连。
- 冻结件 `Doc` 无 content/body 字段——即便抽了正文也无处落（只能塞 `meta`）。

### retrieval/Gate①→Doc→Citation：逻辑建了，但**没接真实源** + **没落库** → 真实数据上**没跑出**
- evidence adapters 存在且完整（`flint/evidence/{news,paper,patent,pricing,competitor,funding,negative,compliance}.py`）：
  `NewsApiSource.search(query)`（`news.py:45`）产 `Doc`——**但只有 title/url/published_at/meta，无正文**，
  且打 `https://api.news.example/v2/...`（:46）= **占位源**。
- Gate① 用**注入的合成 searcher**：`flint/jobs/gate1.py` `Searcher=Callable[[Query],list[Doc]]`（:79），
  内建 `search(query)` 造 `https://{slug}.example/product`、`https://papers.example/...`（:143/:159）
  = **合成 Doc、占位 URL**。
- **持久化缺失**：`gate1.py` 只 `INSERT INTO jobs / job_steps / snapshots`（:202/:250/:260），
  **无 `INSERT INTO docs / citations / claims`**（全仓 grep 无 DocStore / 无 docs 写入）。Doc/Citation 是**每查询内存态**，用完即弃。
- DB 佐证：`gate1_analysis` job ×4、`report` ×6 都跑过，但 `docs=1`（且那 1 条是测试夹具
  `doc_id="m2001-ok" title="t" url="https://x"`）、`citations=0 / claims=0 / facts=0`。
  → **真实 Doc 从未落库**：Gate 拿合成/占位 Doc 跑通了流程，却没有真实源、也不持久化。

### facts：链路空转（确认设计正确）
- `facts=0` 因 `claims=0`（Gate 未落 claim）；claim→fact 提升在下游 compose/freeze。采集不产 fact 正确。

## 三、三选一结论

**混合**——按管段分：

| 管段 | 结论 | 依据 |
|---|---|---|
| 采集→薄卡（M1） | **建+接+跑**（薄卡是设计） | trend 1044→卡 1027；cards.py 卡=keyword+url |
| 卡→厚（抽正文绑卡 Doc） | **没建** | 无抽正文阶段；selectolax 不抽正文；Doc 无 content 字段 |
| retrieval/Gate①→真 Doc | **没接真实源**（占位 .example）+ Doc/Citation **没落库** → 真实数据**没跑出** | gate1.py 合成 searcher；无 docs/citations 写入；DB docs=1(夹具)/citations=0 |
| claim→fact | 空转（确认设计正确，采集不产 fact） | claims=0→facts=0 |

一句话：**卡薄是设计；卡该靠下游 Doc 变厚，但 Doc 生产既没接真实源、也不落库，且没有「抓源文抽正文」这一段——所以库里没有任何可接地的实质证据，主题 why-now 只能引空壳卡 → 具体数字/日期必编造。**

## 四、要让卡变厚须补哪一段（诊断+方案，NEVER 实现；含 STOP 触点）

1. **真实源接入**（retrieval 层）：evidence adapters / gate searcher 现打 `.example` 占位。须接真实源 API 或稳定录制夹具，
   否则 retrieval 永出合成/空 Doc。**STOP 触点**：真实源接入 = 外部抓取 / 付费数据源（V1 非目标本就「接口留好即可」）→ 报 owner。
2. **「抓源文 → 抽正文/claim → Doc」阶段（没建）**：新增阶段取 `card.top_links` 源文抽正文，产**带正文的 Doc** 绑卡。
   **STOP 触点**：冻结件 `Doc` 无 content/body 字段——全文只能塞 `meta` 或需加 `Doc.content` 契约字段 → owner PDD 决策。
3. **Doc/Citation 持久化**（存储层）：Gate① 产的 Doc/Citation 目前不落库；跨阶段引真 Doc 须持久化 Doc + Citation（+ 卡↔Doc 关联）。
4. **接地顺序澄清**（无需改码，口径）：topic-gen 在 retrieval **之前**，此刻只有 card_ids 可引（薄）；真正 Doc 级取证在
   Gate①（下游）。故「主题 why-now 该引卡还是 Doc」= topic-gen 阶段引卡（占位性 why-now）、Gate① 阶段引 Doc（实质取证）。
   若要 topic why-now 就接地干净，要么把 Doc 生产前移到 topic-gen（重架构），要么把 why-now 的实质取证明确留给 Gate①。

**命中 STOP：** 真实源接入（外部抓取/付费源）+ `Doc.content` 冻结件不足——两者均 owner 决策，本诊断只报不动。

## 五、与接地口径长跑的呼应
- 校验器（`flint/grounding.py`）证明「引用≠取证干净」；本诊断证明**根子在数据管线**：库内无实质证据可接地。
- Phase 0.5 强接地 prompt（`topic_gen@2`）能把**卡已有的**日期/内容喂给模型、挡住日期/数字幻觉；但**挡不出卡里没有的证据**
  ——那需要上面 1~3 段补厚。prompt 是免费止血，补厚证据是根治（付费/契约，待 owner）。
