## 2. 蓝本那句「无专属端点」已经过时

README 路由表把 P14 记成「无专属端点：topics + jobs + deliverables 组合」。
**BE-01 本轮把 `GET /projects/{id}` 建出来了——一次查齐。**

一次查齐不只是省几个请求：三次分别查回来的东西对应的是**三个时刻的库**，
而屏上看起来像同一时刻的快照。

所以本屏的入参是**一份总览对象**，不是三个独立列表——
三个独立入参就等于允许三次取数。判据：

- 屏源码里没有 `/topics` `/jobs` `/deliverables` 任何一条路径；
- 组件签名收的是 `overview: ProjectOverviewView | null`。

（端点挂上后接线时 **NEVER 退回蓝本那句话去发三个请求拼**。）

## 3. 三个列表恒存在，且空态各说各的话

BE-01 原话：「三个列表**恒存在**：没有内容时是空数组，不是缺这个键、更不是 404」。

前端照办：空列表画成空态，**不是错误页**。而且三段的空态是**三句不同的话**——
同一句「暂无数据」会让用户以为这三样是同一件事，而「还没有主题」与
「还没有交付物」隔着整条主链路。

每段各带自己的 `data-overview-count`：一段空另两段有内容时，只有那一段是空态。

## 4. 零计算

- **状态直取后端**（`data-row-state` 原样转出）；
