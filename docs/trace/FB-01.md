## 3. 根因与接法

**改前**：`layout.tsx` 零 CSS import，`_ds` 的 7 个 CSS 躺在 `public/_ds/` 里当静态资源，
**从未被应用加载**。EYE-03 首跑把它量成了字节级证据：三屏 dark/light 截图逐字节相同。

**改后**：
- 新建 `web/app/globals.css`（应用层基底：`body` 用 `--bg-page` / `--text-body` / `--font-body`）；
- `layout.tsx` `import "./globals.css"` + `<head>` 里一条
  `<link rel="stylesheet" href="/_ds/<bundle>/styles.css">`。

### 为什么 `_ds` 走 `<link>` 而不是 `@import`

首版在 `globals.css` 里写 `@import url("/_ds/…/styles.css")`，**实测整页 500**：

```
Module not found: Can't resolve '/_ds/flint-design-system-…/styles.css'
  > 25 | @import url("/_ds/flint-design-system-…/styles.css");
Import trace: ./app/globals.css → ./app/layout.tsx [Server Component]
GET /demo 500
```

Next 在**构建时**就去解析那条 URL —— 而它是 `public/` 的**运行时**路径，不是模块路径。
改走 `<link>` 之后浏览器直接取，且正合 `_ds` 的身份：它是**供应商资产**（终检 C6 口径），
搬进构建面就等于把它变成我们的源码，下次重新导出没人分得清哪些改动是谁的。
留在 `public/` 里按 URL 取，目录始终与导出物逐字节一致。

**这次 500 本身就是 acceptance② 那句「NEVER 只断言 import 语句存在」的现场注解**：
`import "./globals.css"` 那行从头到尾都在，样式却一个字节都没到页面。

## 4. 口径收窄：`_ds` 只有一套明色（acceptance② 的一半做不到）

卡面要求「明暗两主题下取到的值**不同**」。回源四点：

1. `_ds` 全目录 grep `prefers-color-scheme` / `data-theme` / `.dark` → **零命中**；
2. `web/` 下（除 node_modules）同样零命中；
3. `tokens/colors.css` 是一整套「纸与墨」明色，无暗色对照；
4. 卡面点名的 `--background` 在 `_ds` 里**不存在**（那是 shadcn 命名，`_ds` 用 `--paper`/`--surface`/`--ink`）。

造暗色调色板是**设计决定** + 动供应商资产 → NEVER 由接线卡自决。
做可做的那一半（token 运行时生效），做不到的那一半立问题单
`docs/blocked/DS-NO-DARK-PALETTE.md`（含 owner 的三选一），并配**自己退休**的断言：
`_ds` 里一天没有暗色声明，问题单一天不许消失；有了就自动放行。

与 GRAPH-06 的「服务端」（F-05）、DESIGN-31 的「共用接口」（F-04）是同一种情况：
**卡面写的前提在真件里不成立**。三次都按同一条处理——对齐真件、收窄口径、留痕、登记。

**一次自造假红被拦下**：首版把 `--paper` 也列进 `LIVE_TOKENS`，实测取到空串。
根因不是样式没生效，而是 `scripts/ui_probe.py` 的 `WATCH_TOKENS` 根本没查这个 token——
**那种红说的是「探针没量」，会被读成「样式坏了」**。改法：清单收窄到探针真查的五个，

**一次自我引用被拦下**：路径存在性断言首版扫原文，被 `globals.css` 注释里那条
（用来说明「为什么不能这么写」的）`@import url("/_ds/…/styles.css")` 咬红。
改为剥掉块注释后再扫——**判据落在代码层，不落在解释代码的话上**，与 GAUGE-06 同型。
