## 决策日志
- **[C1] 冲突判定 = NOT(两维 tag ≥1 不同 且 距离 ≥ δ)**：`_differentiated(a,b,δ) = _tags_differ AND cosine≥δ`；冲突 = 两者任一不满足（两维 tag 全同 **或** 距离 < δ）。测试双向钉：`test_same_tags_both_dims_is_conflict_even_if_far`（距离远但 tag 全同 → 冲突）证明「两者须同时满足」。
- **定点重生成 ≤3**：每轮取首个冲突对、重生成其**后者**（`regenerate` 回调注入，真实即 TS-004 generate_topic 带「更差异化」提示），最多 `MAX_REGEN_ROUNDS=3` 轮。测试 `test_regeneration_resolves_conflict`（一轮解冲突）+ `test_honest_degrade...`（stubborn regen 用满 3 轮）。
- **诚实降级（#7）**：3 轮后仍冲突 → 循环丢弃冲突对**后者** + 记 `dropped_conflicts=[(keep,drop)]` + `degraded=True`；**少出 Topic，NEVER 硬造假差异**（测试断言只剩 `["a"]`、dropped=[("a","b")]）。
- **计数（#2）**：上界 `MAX_TOPICS=8` 在差异化前**硬截断**（`topics[:8]`，测试 9→8）；下界 `MIN_TOPICS=5` 经 `backfill_shortfall(count)` 报补生成数（越下界补生成由编排层据此补，测试 3→2 / 5→0）。降级可使结果 <5（#7 少出，刻意）。
- **[C2] 排序降权**：`sort_by_confidence` 按 `why_now.speculative` 稳定排序（False 先、True 后），speculative 主题排后降权（测试 t1,t3 非 spec 先，t2,t4 后，稳定）。
- **cosine_distance**：numpy 单位化 `1 - a·b/(|a||b|)`；零向量 → 1.0（测试 identical=0 / 正交=1 / 反向=2 / 零向量=1）。
