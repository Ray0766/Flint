## 4. 只标，不改价——三条纪律一个方向

| 纪律 | 不守的后果 |
|---|---|
| 过期照实标记并**保留** | 删了，引用它的那份报告里的数字就成了**没有出处的数字** |
| NEVER 静默替换成新价 | 换掉之后旧报告里的数字与库里对不上，而没人知道何时换的 |
| 扫描**一行价格都不改** | 「顺手更新一下」是最自然的下一步，而改价是另一条路径（重新 seed / owner 录入） |

守法有三层：
- **源码面**：`test_the_scanner_never_writes_to_the_pricebook_table` 禁掉
  `UPDATE pricebook` / `DELETE FROM pricebook` / `INSERT INTO pricebook`；
- **形状面**：`test_the_report_carries_no_new_price` ——报告里**没有**任何新价字段。
  静默替换从「有地方放新价」开始；
- **行为面**（真库）：扫描前后把本卡塞的两行**逐字段比对**，`before == after`。

## 5. 判定与注记都委托既有件

`scan_stale_entries` 的两行正题就是 `check_stale` 与 `price_data_notes`。
