## 三、创建语义（Origin → TopicSeed → Topic）

1. **Origin 五类创建**（重点 combo）：
   - **combo**：用户在工作台选 **2~5 张证据卡**（产品描述 v0.2）+ 写**一句话关联假设**（[D1-a] 必填）→ Origin{kind=combo, payload={card_ids, hypothesis}}。card_ids 校验 ∈ evidence_cards（同簇/跨簇按 owner 裁，见待裁）。
   - idea/domain/competitor/document：各自 payload；hypothesis 可空。
2. **Origin → TopicSeed**：
   - keywords：combo 自带（取所选卡的 keyword_ids → keywords）；其余入口经**关键词抽取器**生成（LLM 步，见待裁 model）。
   - hypothesis：combo 透传；context_text：入口上下文。
3. **TopicSeed → Topic ×N（LLM 生成步，资源触点）**：
   - **combo 出 5~8 个 Topic**（产品描述）；其余入口 1~3（n<2 免差异约束）。
   - LLM 按 seed（keywords + hypothesis + context）生成每 Topic：`one_liner` / `target_user_tag` / `form_factor_tag` / `why_now{claim, evidences}` / `keyword_mapping`；`embedding` 由 flint/embed.py 对 one_liner/keywords 编码（**非 LLM，确定性**）。
   - **[C1] 差异约束**：任意两 Topic **target_user_tag/form_factor_tag 至少一维不同 且 embedding 距离 ≥ δ**；违者**定点重生成 ≤3 轮**；仍不满足 → 标记降级（如少出 Topic 或标注冲突），NEVER 硬造。**δ 是 owner 未定阈值（Open Question，见待裁）**。
   - **[C2] why-now**：`why_now.evidences` 空 → `speculative=true`；排序降权 + 前端灰标。信号角标（novelty/momentum/revival，heat/cluster 面）是天然时间性证据来源，可喂 evidences。
   - **铁律**：Topic 生成的引用/事实照走既有校验面（why_now.evidences.citation_id 须可溯）；LLM NEVER 编造出处——无据 → speculative 或不填，**同指令式重生成的接地纪律**。
4. **Project**：Origin → TopicSeed → topics 落库后建 Project{origin_id, topic_ids}；用户选 → chosen_topic_id。

## 四、Gate 集成（关键风险点，讲清改法）

**风险**：gate1 判定单位是 **keywords**，完全不认 Topic。若直接把 Topic 塞进 gate1 = 大改 gate 内核（不做）。

**改法（最小、不改 gate 内核）**：
- 新增/改 analysis 入口：接受 **chosen topic**（topic_id/seed_id）→ **派生 keywords**（取 Topic.keyword_mapping 或 TopicSeed.keywords）→ 照原样 `run_gate1(keywords)`。gate1 内核**逐字不变**（仍 keyword-unit）。
- **verdict↔topic 链接**：经 **Project.chosen_topic_id → project 的 analysis job → snap-{job}-verdict**（已有链路）。Gate 视图（FV-001 已建 GET /jobs/{id}/verdict）即据实呈现该 topic 的判定。
- **hypothesis 的位置**：关联假设 = **人类判断，非 gate 输入**（gate 判可行性、不判假设对错）；hypothesis 用于**差异化 + 展示**，不喂 gate。这是刻意的——gate 只认证据。
- 待裁：analysis 入口是**改现有 /analysis 加 topic_id**（keywords 仍可选）还是**新端点 /projects/{id}/analyze-topic**；见待裁。
