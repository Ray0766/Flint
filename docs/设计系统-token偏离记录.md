# 设计系统 · token 偏离记录

> **这份文档的用途**：实现用的 token 与 Claude 设计包 `_ds/tokens/colors.css` 的**每一处不同**都记在这里。
> owner 裁决 ①：改值可以，但 **NEVER 静默分叉** —— 分叉必须留痕、必须说明原因、必须可复算。
>
> **权威关系**：`_ds` 是视觉语言来源；`V0 files 前端设计/app/globals.css` 是实现真相。
> 两者冲突时以本表为准，本表未列出的项一律与 `_ds` 一致。
> **机器校验**：`scripts/check_contrast.py`（两套主题 × 全部同屏组合，正文 ≥4.5 / 大字 ≥3.0，
> 不达标即 exit 非零）。表里的每个数字都由该脚本实算复现。

---

## 判据

WCAG 2.1 相对亮度公式。正文级 ≥ 4.5:1；大字与传达信息的非文本元素 ≥ 3.0:1。

**本项目的一条加严**：11px 元信息（`--ink-3` 承载）在本产品里**按正文级要求**——
出处、id、时间戳都是要逐字读的内容，不是装饰。故 `--ink-3` 也须过 4.5。

**日间三种底**（最差底 = `--raised`）：`--base` #EDEEE6 / `--surface` #F7F8F3 / `--raised` #E3E5DA。

---

## 偏离清单（共 3 处）

### 1. `--ink-2` 次级文字：`#5A6A6E` → `#46565A`

| | 值 | 压 base | 压 surface | 压 raised |
|---|---|---|---|---|
| `_ds` 原值 | `#5A6A6E` | 4.83 | 5.29 | **4.43 ✗** |
| 实现取值 | `#46565A` | 6.56 | 7.18 | **6.02 ✓** |

**原因**：`_ds` 原值在抬升层（`--raised` #E3E5DA）上只有 4.43，不达正文标准。
抬升层在本实现里承载真实正文（报告页头元信息条、quality_card、加载骨架容器、页脚站点图），
不是纯装饰面，故必须过门。

### 2. `--ink-3` 元信息：`#8B9799` → `#54646A`

| | 值 | 压 base | 压 surface | 压 raised |
|---|---|---|---|---|
| `_ds` 原值 | `#8B9799` | **2.57 ✗** | 2.82 | 2.36 |
| 实现取值 | `#54646A` | 5.27 | 5.77 | **4.84 ✓** |

**原因**：`_ds` 原值三种底全部不达标（最好的一档也只有 2.82）。
按上面「11px 元信息按正文级要求」的加严，取到三阶全过且仍明显低于 `--ink-2`（层次不塌）。

**owner 已知会的边界**：`_ds` 把 `#8B9799` 定位为「标签、元信息」色。
若将来要恢复原值，**MUST 同时把它降级为纯装饰用途**（不承载需要逐字读的内容），
否则无异于把可读性问题藏回去。

### 3. `--rail` 细线（承载状态的那一档）：`#B9BFAE` → `#7E866F`；夜间 `rgba(255,255,255,.20)` → `.36`

| | 值 | 压 surface |
|---|---|---|
| `_ds` 原值（日） | `#B9BFAE` | **1.77 ✗** |
| 实现取值（日） | `#7E866F` | **3.56 ✓** |
| 原实现（夜） | `rgba(255,255,255,0.20)` | **1.90 ✗** |
| 实现取值（夜） | `rgba(255,255,255,0.36)` | **3.34 ✓** |

**原因**：`--rail` 在本实现里承载一套**状态词汇**——虚线边 = `unknown` 竞品 / `degraded` 降级 /
保护只读 / 缺口。它是「传达信息的非文本元素」，须过 3:1。原值近乎看不见。

**未偏离**：`--rule`（纯分隔细线，不承载状态）保持 `_ds` 原值 `#D2D6C9`，
也因此**不纳入对比度门**——它没有需要传达的信息。

## 非偏离但需知会的两条纪律

### `--spark` 必须双值（不是偏离，是 `_ds` 未覆盖暗色）

`_ds` 只定义了纸感浅底的 `--rust #B4472C`。暗色主题下该值只有 3.21，不可用。
故：**日间 `#B4472C`（纸底 4.63）/ 夜间 `#FF6B4A`（卡面 6.17）**。
单一取值不可能同时达标——`#FF6B4A` 在纸底只有 2.41。
两者都只属 blocking / 409 EXPORT_BLOCKED / 503，装饰与强调 NEVER 挪用。

### `--sulfur` 只作背景，且只属营销屏（owner 裁决 ③）

- **只作背景**：纸底 1.57，NEVER 作文字色。黄底须配深字（`--on-accent` 压其上 8.07）。
- **只属营销屏**：首页与 `/how-it-works`。数据屏（广场 / 工作台 / combo / Gate / 报告）
  NEVER 使用——与 glow 同样圈地，保证告警色在要紧处仍然唯一。
- **机器校验**：`scripts/check_contrast.py` 的 `scan_sulfur_confinement()` 扫描前端源码，
  数据屏出现 `--sulfur` / `bg-cta-bg` / `text-cta-fg` 即失败。白名单在该函数的 `SULFUR_ALLOWED`。

## 变更此表的规矩

改动任何一处 token 值 → 先跑 `scripts/check_contrast.py`，再把新旧值与三种底的实算数字补进本表。
**NEVER 只改值不更表**；**NEVER 为了让门通过而调松判据**（4.5 / 3.0 是固定的）。
