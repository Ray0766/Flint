## 发现与决策
- **关键缺口**：`GET /deliverables/{id}` 只回**元信息**；`/render?fmt=` 回**已渲染**
  markdown/html。**无端点回结构化 Block 树 JSON** —— L0 逐块原生只读渲染（8 类
  BlockType 各组件 + 保护标志）缺读契约。补 `GET /deliverables/{id}/blocks`。
- **环境事实**：本机无 `node`/`npm` → 纯前端 L0 UI 无法在此构建/验收（Q-005，
  与 Docker/GTK 同类环境缺口）。但**读契约是后端/Python 面、node 无关**、本地 PG
  可验收 —— 故本 turn 交付 FE-000（L0 唯一可在此构建的依赖），UI 待 Q-005 解除。
- **实现**：`[asdict(block) for block in load_tree(...)]`；先 `load_deliverable`
  （KeyError→404）再 `load_tree`；稳定序 (section_id, block_order)；content 判别
  联合经 asdict 递归无损带出（kind 判别字段保真）；保护标志 locked/author/
  user_modified + needs_review 一并输出。只读、NEVER 回写（Block 树唯一真相 [D3]）。
