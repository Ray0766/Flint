## 二、映射表是一处，不是各组件各写一句

`web/lib/i18n/enumLabel.ts`：七族 37 个值，每族写明**真相源**。
判据 `test_the_family_matches_its_source_verbatim` 从冻结件/后端源码**解析**成员集判等——
**冻结件多一个成员而这里没给标签，当场红**（这就是卡面那句「新增枚举没给标签则判红」）。

标签走既有 i18n 通道（`t()` → `messages/{zh,en}.json`），中英各 37 条。
`test_no_component_hardcodes_a_label_of_its_own` 盯着组件里 NEVER 出现「证据不足/不可行/红海/机会」
这类判定话术的字面量——各写一句的话，同一个值在判定屏与卡面会是两句话。

## 三、「未知 ≠ 没查过 ≠ 没接」怎么落到词上

| 值 | 中文 | 英文 |
|---|---|---|
| `authority.unknown` | 未知（查过了，定不了档） | Unknown (checked, tier undetermined) |
| `availability.not_checked` | 还没查过 | Not checked yet |
| `availability.not_provided` | 接口未提供 | Endpoint not provided |
| `strength.unknown` | 未知（信号不足，NEVER 当成弱） | Unknown (not enough signals; never read as weak) |

`strength.unknown` 那句照冻结件的原话（`contracts/models.py:647`「信号不足 → unknown（不是 weak）」）——
把它读成「弱」会让 `unknown 阻断 C` 那条保守规则在屏上失去理由。

判据两条：三者互不同词（中英各比一次）；「未知」必须说得出「查过了」——
只写「未知」两个字，它与「没查过」在屏上还是分不开。

## 四、主判据：真屏上不出现下划线小写原值

前三条都能在源码层作弊（表写得漂亮而组件根本没调它）。第四条作不了弊：
探针打开真屏取 `document.body.innerText`，与已登记的原值求交集，非空即红。
配两条防空转：`test_the_probe_actually_saw_something`（取到的文字 >40 字，
空字符串会让主判据无条件通过——那是最坏的绿）、
`test_the_ruler_would_catch_a_raw_value`（阴性对照：塞一个原值进去，正则必须认得出）。

**实跑当场抓到两处**（不是想象中的）：`gate` 屏上的 `not_saturated` 与 `unknown`。
`unknown` 是前端渲染的 → 本卡修掉；`not_saturated` 是后端拼进散文里的 → 见下。

## 五、一处停下报 owner（`worker.md §9.2`）

`flint/gate/rule_d.py:44` 写着 `missing_what=f"竞品扫描覆盖未达标（{coverage.reason}）"`——
**原值是后端拼进句子的**。前端对 `missing_what` 的做法是原样渲染，那是对的
（`ErrorState` 的既有纪律：后端自己的说明原样带出来，改写就把唯一有用的线索丢掉）。

改它要动 v0.4 已 verified 的实现 → **停下报 owner**，单据
`docs/blocked/BACKEND-PROSE-EMBEDS-RAW-ENUM.md`（含建议修法：`GapHint` 把
「原因码」与「给人看的话」分成两个字段，前端的 `coverage` 族已备好）。

判据里把这一条**逐字登记成例外**，并配反向判据
`test_the_registered_backend_prose_still_shows_up`：**这句话哪天不在屏上了，判据会红并要求来删这一行**
——NEVER 留一条修好之后还赖着的豁免。

返工三轮，每轮都是尺子先红：
① 英文标签判据首版要求「与原值不同」，把 `failed → Failed` 判成作弊——
**那是判据在制造坏文案**（逼人给单词型枚举编一个啰嗦的同义词）。收窄成「不是下划线形态」，
下划线型仍要求不同；
② 真屏判据抓到 `not_saturated`（后端散文，见第五节）与 `unknown`（前端，已修）；
③ `i18n_scan` 两次红在**族表的 `source` 字段**里有中文——那是给人读的注释性数据，
但它是字符串字面量，尺子分不出来也不该分。改成英文，NEVER 去改尺子放它过。
