## 2. 最硬的一条：NEVER 返回可靠度分值

技术约束清单第 1 条原话：「是否出现可靠度进度条、百分比、星级、雷达图，
或任何把布尔/枚举画成连续量的表达？**后端不返回这类分值**。」

所以覆盖率给的是**分子与分母两个数**，不是一个比例：
「6 个块里 1 个有证据引用」前端能列出来；「引用覆盖率 17%」前端会拿它画进度条——
**而那条进度条没有出处**。给了商，也就没人再去想它是怎么算出来的。

判据三层：响应里不许出现 `percent`/`ratio`/`score` 这类键；响应里**每个数都必须是整数**
（出现小数就意味着有人算了商）；**模块里一处除法都没有**（判在 AST 上——
注释里写「NEVER 给比例」不算除法）。

## 3. 三个语义分界

### 3.1 分母只算 system 且未被用户修改的块

冻结件 `Block` docstring [审3] 原话。把用户块算进去的话，
用户自己写的段落会拉低「我们的引用覆盖」——那个数说的就不再是系统生成的质量了。
**被排除的块数一并报出来**，否则读的人不知道分母为什么比总块数小。

### 3.2 证据引用与元信息引用**分开数**（这一条是判据逼出来的）

第一版把 `card_ref`（质量卡）与 `hints_ref`（缺口清单）也算进覆盖率，
判据当场红了。想清楚之后：

「引用覆盖」说的是**结论有没有出处**（S2-2 三条出处通道 + 由事实派生的图表）。
而质量卡与缺口清单是**关于这份交付物的元信息**，不是证据——
把它们算进覆盖率，**一份满是缺口提示的交付物会显得「引用充分」**，
那正好把这个数的意思弄反了。

两类**都进**「未解引用」检查：元信息 ref 解不开同样是坏链接。

### 3.3 「没检查过」与「检查过、是 0」分得开

未解引用数要真去解一遍才知道。解引用器没注入时本端点**不报 0**——
报 0 等于说「查过了，一个都没有」。它报 `status: "not_checked"`，
且**连 `count` 这个键都不给**（给了它就还是一个数）。

这是本轮反复出现的同一条：空值与未知值 NEVER 挤进同一个表示
（DOC-01 的 `content=None`、PAY-02 的「配成 0 与没配」、PAY-01 的「实读与未读到」）。

## 4. 复用既有闸门

阻断态四项（`blocking_block_ids` / `blocking_open` / `advisory_open` / `exportable`）
全部来自 `gatekeeper.check_export`——导出门用的就是它。

**NEVER 另写一遍判断**：两处各判各的话，质量卡说「没有阻断」而导出却 409，
用户无从判断该信哪个。判据除了查 `check_export` 在不在，还查模块里
**不许再出现 `needs_review`**——出现就说明有人在这里又数了一遍。

## 5. 写卡时被冻结件教了三次

| 我写的 | 真件 |

| `FactRefContent(kind="fact_ref", ...)` | **没有这个类**。带 `fact_id` 的是表格里的 `FactCell` |
| `GapHintsContent(kind="gap_hints", ...)` | 真名是 `GapNoticeContent(kind="gap_notice")` |

三处都是**按记忆造类名/字段名**，冻结件一读就现形。判据先红、然后照真件改——
这正是 S3「实现 MUST 与冻结件类型逐字一致」的日常形态。

另有一处是我自己的期望值算错：分母写成 4，实际是 6——
**待复核的块也是系统生成的**，它们照样该被问「有没有引用」。

## 8. 登记未做

1. **没挂进任何 ASGI 应用**。与 BE-01/BE-02 同——装配超出本卡 outputs，
   **前端现在还调不到它**。
2. **`ref_resolver` 没有真实实现**。真接线要去问 `/facts` `/citations` `/charts`
   `/cards` `/hints` 五个 deref 端点（或直接查库）。未注入时本端点报
   `not_checked`，**不会假装查过**。
3. **`load_blocks` / `deliverable_owner` 也只是注入点**：真实现要读
   `blocks` 与 `deliverables` 两张表。
4. **覆盖率只看「块里有没有 ref」，不看 ref 指的东西够不够格**。
   一个块引了一条 `status=="disputed"` 的 fact，在这里仍算「有引用」——
   争议态是另一条线（S2-4），要不要并进质量卡是产品口径，卡面没写。
5. **对齐率没做**。[审3] 那句话同时提到「覆盖率/对齐率」，本卡只做了覆盖率——
   对齐率要读 claim 的 `alignment`，属两段式对齐那条线。
