## 2. 提案代码（拟插入 models.py「数据与索引层」段尾，Cluster 之后）

```python
# ═════════════════════ 血缘日更产物 [A1][v0.4 增补，Q-002]

@dataclass
class ContinuedEvent:
    kind: Literal["continued"]
    cluster_id: str                  # 既有簇，ID 跨日稳定
    keyword_ids: list[str]           # 当日归入的关键词


@dataclass
class SplitEvent:
    kind: Literal["split"]
    new_cluster_id: str
    parent_cluster_id: str           # 一旧对多新：每个新簇单父
    keyword_ids: list[str]


@dataclass
class MergedEvent:
    kind: Literal["merged"]
    new_cluster_id: str
    merged_cluster_ids: list[str]    # 多旧对一新：旧簇全部 merged_into=new
    keyword_ids: list[str]


@dataclass
class NewClusterEvent:
    kind: Literal["new"]
    cluster_id: str
    parent_cluster_ids: list[str]    # 1:1 弱链接来源可空（血缘可追溯）
    keyword_ids: list[str]
    naming_degraded: bool            # LLM 命名降级为 top 关键词（不阻塞语义）


@dataclass
class RevivedEvent:
    kind: Literal["revived"]
    cluster_id: str                  # dormant → active，ID 复用不重铸
    keyword_ids: list[str]


LineageEvent = (
    ContinuedEvent | SplitEvent | MergedEvent | NewClusterEvent | RevivedEvent
)


@dataclass
class CentroidDriftAudit:
    """漂移防护留痕：单日簇心 cosine 位移超限被拒绝的审计记录。"""
    cluster_id: str
    attempted_shift: float           # cosine 距离
    max_shift: float
    action: Literal["rejected"]


@dataclass
class LineageResult:
    """血缘日更批的唯一产物：每日一份、append-only；参数快照使批次可复现
    （铁律 3）。审计视图 = 本实体按 cluster_id 展开的时间线。"""
    day: date
    events: list[LineageEvent]       # 判别联合（审16：不留裸 dict）
    dormant_cluster_ids: list[str]   # 当日转入 dormant（永不物理删除）
    drift_audits: list[CentroidDriftAudit]
    tau_match: float                 # 当日参数快照（Open Question 阈值在案）
    tau_link: float
    dormant_after_days: int
    generated_at: datetime
```

## 3. 字段 ↔ 既有实现映射（零虚构）

| 草案字段 | 来源模块（已 verified） |
|---|---|
| ContinuedEvent | M1-024 ContinuationResult.assignments |
| SplitEvent / MergedEvent | M1-025 LineageDecision(kind=split/merge) + merged_into |
| NewClusterEvent(.naming_degraded) | M1-025 kind=new + M1-027 register_new_cluster 降级标志 |
| RevivedEvent | M1-026 RevivalEvent（ID 复用） |
| dormant_cluster_ids | M1-026 apply_dormancy |
| CentroidDriftAudit | M1-028 DriftAudit（字段同名同型） |
| tau_match / tau_link / dormant_after_days | 三个配置化阈值的当日快照 |

## 4. 落库与审计视图（M1-029 实现口径，非冻结内容）

- 表 `lineage_results(day PK, events JSONB, dormant_cluster_ids JSONB, drift_audits JSONB, tau_match, tau_link, dormant_after_days, generated_at)`——判别联合序列化入 JSONB（E2 总则）；append-only，migration-0003。
- 审计视图 `lineage_audit`：events 按 cluster_id UNNEST 的逐簇时间线（任一簇可查完整血缘链；标注工具 M1-038 直接 SELECT 导出 yaml）。
