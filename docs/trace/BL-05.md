## 3. 三个模块**一个字都没改**——这是本卡的形状

卡面把 `flint/hotness.py` / `burst.py` / `weaksignal.py` 列在 **inputs**，
把 `flint/config.py` / `harness/tune_hotness.py` / 测试列在 **outputs**。

所以「代码里零硬编码初值」在本卡的读法是：**初值只有一处**——三个模块的
dataclass 默认值（acceptance③ 的「配置缺失时用当前初值」指的正是它们）。
通道只负责**读配置覆盖它们**，NEVER 在 `config.py` 里再抄一份数：
抄一份就有了第二个真相，而两个真相里总有一个是旧的。

`test_the_defaults_in_the_three_modules_are_untouched` 把十个初值逐个写死在测试里
（1.6 / 1.0 / 0.6 / 0.3 / 0.4 / 2.0 / 1.0 / 40.0 / 1.0 / 1.0），
`test_theta_rel_and_delta_defaults_are_untouched` 守 θ_rel=0.6。
**改了它们的人会在这两条上红，然后被迫解释是不是 owner 定的**——
而那正是 acceptance② 的「本卡 NEVER 改任何默认值」要的效果。

## 4. 认不出的键**必须报错**

`load_tuning({"hotness": {"typo_gravity": 1.9}})` 抛 `TuningError`。

静默忽略的后果很具体：owner 以为自己调了参，实际跑的还是初值，
而 A/B 对照表上两组数字**一模一样**——他会得出「这个参数没用」的结论，
然后放弃一个其实有效的旋钮。

`TUNING_KEYS` 是**闭集**（12 个），`test_every_documented_knob_is_reachable_from_the_config`
逐字对照卡面点名的那一串。少一个就意味着那个数只能改代码。

## 5. 「读到了」与「生效了」是两件事

12 个旋钮各有一条参数化用例（写进去 9.5，读出来必须是 9.5）——这只证明**读到了**。

真正的证据是 `test_changing_the_config_changes_the_ranking`：同一批数据
（一簇高而平、一簇低而陡），把 β/γ 调到 0 时高的那簇第一，把 α 压到 0.1、
β/γ 拉到 3.0/2.0 时陡的那簇第一。**排序真的翻了**，参数才算接在算式上。

## 6. 半标定比没标定更危险

`tuning_note` 的输出分三档：

| 情况 | 那一行长什么样 |
|---|---|
| 无配置 | `参数来源 = 代码内初值…｜**未标定**：本结果 report_only，NEVER 当作调参结论` |
| 部分覆盖 | `…｜来自配置：hotness.gravity｜仍是初值（未标定）：hotness.w_agg、…、theta_rel` |
| 全覆盖 | 只有来源，不带警告 |

首版把「未标定」写成了「只要有一个键没覆盖就整体喊」，于是**部分覆盖也喊**——
`test_a_calibrated_profile_does_not_cry_wolf` 当场红。改法不是把警告删掉，
而是**把它说准**：拆成「全覆盖不喊」与「部分覆盖点名哪几个仍是初值」两条用例。

理由写在函数里：「已标定」是个整体印象，而真相往往是「G 标了、θ_rel 没标」——
不写出来，没标的那些会被一起算成标过的。

**警告只在一处生成**：`UNCALIBRATED_SOURCE` 里原本也带着「未标定」四个字，
实跑一屏才发现同一行里出现了两次——两处各写一遍的结果是读的人开始跳过它。

## 7. 跑批器：连写回的能力都不给

调参是 owner 决策（S4 未决项）。一个能顺手写回的跑批器，迟早会有人
「跑完顺便存一下」——**那一刻未决项就被执行侧定了**，而 owner 连对照表都没看过。

所以 `harness/tune_hotness.py` 里没有任何写动作，且
`test_the_runner_never_writes_anything_back` 从源码面禁掉四类写法
（`write_text` / `json.dump(` / `os.environ[` / `= HotnessConfig(`）。

`report_only` 恒 True，`moved` 为空也是有信息的：它说明这两组参数在这批数据上
分不出差别——**那本身就是一条结论**（别在这个旋钮上继续花时间）。

   看起来像标定过的数。owner 要调参时自己交一份 json。
4. **A/B 只比热度排序**：burst / weak_signal / θ_rel / δ 四组参数进得了通道，
