## 2. 三通道各回各的（S2-2）

Fact / PriceCell / ProfileRef 三条出处通道互不混用。本模块的形态：

- 价格那条路上不出现 profile 字段（变异⑧）；
- 涉我那条路上不出现价格与 fact（变异⑲）；
- **本模块连 `flint/api/deref.py` 都不 import**——混用的第一步恒是
  「顺手在这里也解一下 fact」，够不着就顺不了手。

判据分两层：模块标识符层（够不着 Fact 通道）与**响应键层**。
第二层是变异⑲ 逼出来的：`"fact_id"` 是个字符串键，不是标识符，
从第一层下面走得过去（详见 §5）。

## 3. 过期价：给，但要标

`stale.py` 的口径是「过期仍可用 + 双重标注缺一不可」（黄标位 + 年份注记）。
本端点因此**把价格与时效状态一起返回**：

- 变异①（照给但不标）→ 红：静默用旧价的后果是报告里那个数看起来和新价一模一样；
- 变异②（过期就不给价）→ 红：那是把「旧」当成「没有」，用户连参考值都拿不到。

时效判定与质量卡注记**全部转调**（`check_stale` / `price_data_notes`），
判据钉死模块里没有 `30.44` 这个常数、也没有任何 `timedelta`（变异③）。

**无出处的条目**：查得到，但 `citable: false`——能不能引由既有构造点
`make_price_cell` 说了算（本模块拿 quantity=1 探一次，捕 `PriceChannelViolation`），
NEVER 另判一次（变异⑤⑥）。

## 4. 视角是判出来的，不是请求里带的

`viewer_role` 若能由调用方递进来，等于人人可自称 owner，D12 的敏感度口径当场作废。
所以：

- 经 `viewer_role_for(caller, profile)` **判定**（变异⑯ 加一个
  `X-Viewer-Role` 头 → 红）；
- 处理函数的参数里**连一个叫 role 的都没有**（判据钉在签名上）；
- **判不出视角 → 404**，而不是给一份过滤后的 profile（变异⑪）——
  给了就等于承认「这个 profile 存在」。

字段解引用先按视角裁再解：于是 owner_only 字段走的是
`make_ref_or_gap` 的「解不出 + 该路径 owner_only」分支，
得到 `missing_permission` 而**不是** `missing_data`（变异⑬）。
审8 原话：权限缺口**绝不伪装成缺资料**——伪装的话，团队成员会去「补录」
一份 owner 不想给他看的东西。

## 5. 变异考逼出来的三条判据（本卡最值钱的部分）

二十个变异体里 **⑰⑲⑳ 全活**，三条都是真洞：

| 活下来的变异 | 洞在哪 | 补的判据 |
|---|---|---|
| ⑰ profile 回一个 `owner_id` | 价格那条路有形状判据，**涉我这条路一条都没有** | 响应键集合逐字断言 |
| ⑲ 涉我响应里塞 `"fact_id"` | 三通道判据只判了**模块标识符**，而它是个字符串键 | 递归扫响应键，禁 fact/citation/claim/price |
| ⑳ 字段路的两种 404 用不同码 | 同码判据只覆盖了 `/profile/{id}`，**没覆盖 `/profile/{id}/fields/{path}`** | 字段路上也比一次 |

三条的共同形状：**判据覆盖了一条路，没覆盖它旁边那条**。
一条路上想清楚的事，要在每一条同类路上都判一遍。

## 7. 登记未做

1. **没挂进任何 ASGI 应用**。BE-01~11 十一张卡同一件待办。
2. **`load_entries` / `load_profile` 是注入点**。价格表真接线走
   `flint/pricebook/seed.py#load_pricebook`（读 YAML）或 E2 的表；
   profile 走既有 `PgProfileStore`（`flint/profile/store.py` 里已有 SQL 实现）。
3. **`viewer_role_for` 是注入点，且当前只能判出 owner**。
   判「同事」要 memberships 表——**那张表在本仓不存在**（BE-05 已登记同一件事）。
   所以没注入真实现时非 owner 一律 404。**NEVER 猜一个 team**：
   猜错的方向是把 owner_only 字段给了不该看的人。
4. **不算金额**。单价 × 数量属预算表那条路（`validate_budget_table` 守着），
   数量在 `PriceCell` 上、不在条目上，本端点手里根本没有它——
   算不出的值不返回，也不填 0（变异⑦ 钉住）。
   要接的话是另一张卡：入参带 quantity、出参给区间，且必须与
   `make_price_cell` 的构造口径对齐。
5. **`find_naked_profile_values`（裸值检测）没接**。它属**写入面**
   （生成的正文里不许出现 profile 裸值），本卡是只读端点，用不上它。
   真正该调它的是 compose/render 那条链，登记。
6. **PriceBook 不按 owner 切**。`PriceEntry` 冻结件里**没有 owner 字段**，
   它是全局共享的参考表（与 `flint/api/deref.py` 里
   「本表全局共享，不按 owner 切」同一口径）。
   若日后要支持用户自备价格表（`source == "user_override"` 那一种），
   得先给冻结件加 owner —— 属 owner 变更通道。
