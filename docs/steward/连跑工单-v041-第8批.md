### B 组 · 两条缺陷（`FIX-16/17`，2 卡）

**`FIX-16` 是这批第二要紧的**。steward 2026-08-08 四次探针实测：

```
GET /facts/fact-demo-vecdb-cost
  不带 X-User-Id  → 200 真内容
  self / demo / u-demo → 全部 404
GET /price-entries/{id} → 恒 422
GET /citations/{id}     → 两种都 200
```

**匿名比带身份更有权限，方向是反的。** 而前端今天一个身份头都不发（`derefClient.ts` 只发 `Accept`，`API_USER_ID` 默认空串）——**报告屏能看到那些事实与价格，恰恰因为它匿名**。登录态一上，那一屏就丢内容。

`FIX-17` 是 owner 已同意的甲：每条陈述前加一行**可见**来源名。
